# v1.0.0 Build Pipeline Performance Baseline

**Date:** 2026-08-14
**Milestone:** v1.0.0 (self-hosting closure byte-equal, tagged `eabee0d`)
**Sprint context:** 性能基线 — src (C 端) vs src0 (jhyy 自举端) 编译同一批 `.jhyy` 源

## 测试方法

每个 workload 跑 3 次（首次 warmup 不计），取最小值（min 减 Windows 进程启动噪声）。

**测量方式：** `/usr/bin/time -f "%e"` 包 `jhyy build` (纯编译器工作：lex+parse+sema+codegen → `.il`，不含 QBE/gcc)。

**不测 `jhyy compile` (含 QBE + gcc)：** 那两段是 native binary，与编译器源语言无关，对比无意义。

## 系统

- OS: Windows 10 Home 10.0.19045
- MSYS2: 3.6.4 (x86_64)
- 编译器二进制:
  - `jhyy.exe` (C 端, src/)     `c9cff7609bae4666b843effef4e08d8f7d751ce5bbe24baa6bbe2573c2cb085d`
  - `jhyy_v1.exe.exe` (自举, src0/) `3183594c15b03a33a2c5ec9a1a36eab9d1cd0500cce92da50241970740d72fd1`

## 结果

| workload       | 行数  | jhyy.exe (src) | jhyy_v1 (src0) | v1/src 比例 |
|----------------|-------|----------------|----------------|-------------|
| util.jhyy      |  354  | **0.21s**      | 0.18s          | 0.86x       |
| lexer.jhyy     |  867  | **0.22s**      | 0.24s          | 1.09x       |
| parser.jhyy    | 2498  | **0.25s**      | 0.30s          | 1.20x       |
| codegen.jhyy   | 3561  | **0.26s**      | 0.30s          | 1.15x       |

3-run min，3 次 raw 数值在 § Raw timings。

## 解读

- **小文件基本平手** (util / lexer)：v1 偶有 0.86x (快一点) 也属噪声范围，差异 < 50ms
- **大文件 v1 慢 15-20%** (parser / codegen)，绝对值差 ~50ms
- **Windows 进程启动 ~50-100ms** 占比不小：纯编译器工作时间更小，真实差距 < 10%
- **byte-equal + 性能同档** = v1.0.0 闭环两个维度都站得住

## Caveats

1. **噪声**：单 run 抖动 ±30ms，3-run min 能压住大部分但不能完全消除。要更高信噪比用 5-10 runs
2. **冷启动未隔离**：第二次起 OS file cache 命中，`src0/*.jhyy` 的 read 全在内存，跟生产环境可能不同
3. **不含 QBE/gcc 阶段**：要看端到端需另测 `jhyy compile`，那部分 ~3-16s 由 QBE/gcc 主导，src vs src0 差异 < 1s（在 14-16s 总耗时里 < 7%）
4. **Windows-specific**：Linux 上进程启动 < 5ms，绝对数值会更小但 src vs src0 比例应基本一致

## 复现

```bash
cd C:/Users/liuzhen/Desktop/coding/JiHuiYiYou
mkdir -p /tmp/jhyy-bench
run3() {
  local cmd=$1
  bash -c "$cmd" >/dev/null 2>&1  # warmup
  for i in 1 2 3; do
    { /usr/bin/time -f "%e" bash -c "$cmd >/dev/null 2>/dev/null" ; } 2>&1 | tr -d '\n'
    echo -n " "
  done
  echo
}
for w in util.jhyy lexer.jhyy parser.jhyy codegen.jhyy; do
  for c in jhyy.exe jhyy_v1.exe.exe; do
    printf "%-15s %-15s | " "$w" "$c"
    run3 "./compiler/build/bin/$c build compiler/src0/$w -o /tmp/jhyy-bench/$(basename $w .jhyy).il"
  done
done
```
