## Implementation per iteration (ship record)

### ✅ Iteration 1: A1 — register-suffix in emit_call (~15-25 LOC) — SHIPPED

**File**: `compiler/src0/codegen_amd64_emit_call.jhyy` (emit_call fn, target_tag dispatcher for Win/SysV)

**Bug**: emit `movl %rcx, ...` (32-bit mov + 64-bit reg) for 64-bit context. QBE side 不写 32-bit suffix (因为 QBE 自己 dispatch),self-backend 写 movl 但 reg 是 64-bit rcx/rdx → as.exe reject.

**Fix pattern**: 在 target_tag dispatch (Win/SysV 都 ~7 args: rcx/rdx/r8/r9 + stack) 加 mov size 跟 arg type 对齐 — `*u8` / `*T` / 64-bit int → `movq`;`i32` / `u32` / bool → `movl`。

**Tests**: float_cmp + generics_fn_call_site_inference + generics_fn_turbofish_basic — 3 tests PASS。

### ✅ Iteration 2: A2 — const data emit gap (~30-50 LOC) — SHIPPED

**File**: `compiler/src0/codegen_amd64_*.jhyy` (search for data section emit, likely `codegen_amd64_emit_mem.jhyy` 或 main.jhyy `emit_data_global`)

**Bug**: const 数组 / struct literal reference emit 但 init literal data section 漏。QBE side `data $name = { b 97, b 98, ... }` 自动 emit, self-backend 漏。

**Fix pattern**: 在 const literal parse path 加 `emit_data_section(name, init_bytes)` call,emit `.data\n.globl <name>\n<name>:\n.byte ...`。

**Tests**: const_array + const_struct_array + dungeon_game + generics_fn_call_site_mixed_dedup — 4 tests PASS。

### ✅ Iteration 3: C.1 — int-width / extsw silent-skip (~25-40 LOC) — SHIPPED

**File**: `compiler/src0/codegen_amd64_lexer.jhyy` (next_token_binop / main dispatcher) + `codegen_amd64_emit_call.jhyy` (emit_binop extsw branch)

**Bug**: 跟 v2.11.12 真修的 shl/shr missing 同 pattern — lexer 不识 `extsw` → silent skip 1 byte/iter → extsw IL keyword 不 emit → `csltl` 等比较 op operand 拿 garbage → wrong exit。

**Fix**: 跟 v2.11.12 shl/shr fix 同:
1. `next_token_binop` 加 'e' dispatch (跟 's' 同 pattern, 'exts' = extsw / extsl / extsh / extsb)
2. main dispatcher 'e' branch 加 exts check
3. emit_binop 加 exts dispatch branch emit `cltq` / `cdqe` / `cqo` / `movsbl` / `movswl` / `movzbl` / `movzwl` (跟 op 4-char 名 + size suffix 对应)

**Tests**: arith + int_width_arith + int_suffix + u32_let_inferred + u32_let_inferred_5 + top_level_let_mut_test — 6 tests PASS (+ top_level_let_mut_types 算 Cluster B)。

### ✅ Iteration 4: C.2 — Cap<T> sizeof default → **实测 cne substring missing (1 LOC 真修, 跟 plan 估 "sizeof default 30-50 LOC" 严重错归因)** — SHIPPED + scope DOWN 触发

**Plan 估 root cause**: `sizeof(Cap<i32>)` return 10 instead of 8。`Cap<T>` = 8 byte (per `jhyy-abi-v1.0.0.md` + D6 决定),但 emit_sizeof default 给 10 (大概 4 bytes for tag + 4 for data ptr,actual 是 8 = 1 ptr)。

**实测 root cause**: sizeof(Cap<i32>) 在 sema `type_size` (types.jhyy:366) hardcode 8,IL emit `%t2 =l copy 8` 跟 QBE side byte-equal。**真根因是 `if s_cap != 8` emit `cnel %t8, %t11`**,cnel 在 emit_binop substring miss → fall through add → cap_table_basic got=10 (8+8=16 ≠ 0 → goto then-branch → return 10)。

**File**: `compiler/src0/codegen_amd64_emit_call.jhyy:1077` (cg_find_sub "cnew" 4-char substring → "cne" 3-char 真修)

**Bug**: v2.11.12 emit_binop dispatch 用 `"cnew" 4-char` substring match,只 match `cnew`,**漏 4-char `cnel` / `cnes` / `cned`** (QBE compare-not-equal with size suffix per codegen.jhyy:854-857) → fall through to `add` fallback → emit `addl src1, src2` + `cmpl $0, sum` 而非 `cmpl src2, src1` + `setne %al` + `movzbl %al, %eax` → 任何 64-bit / f32 / f64 context 的 `!=` 比较 全部 fail。

**Fix pattern**: 改 substring match `"cnew" 4-char` → `"cne" 3-char` → catch 全部 4 个 cne_* op (cnew/cnel/cnes/cned)。**Verify 无 false positive**:全 codegen.jhyy 搜 cx* ops (`ceqd/ceql/ceqs/ceqw/cned/cnel/cnes/cnew/csltl/csltw/cslel/cslew/csgtl/csgtw/csgel/csgew/cultl/cultw/culel/culew/cugtl/cugtw/cugel/cugew`) 都没有 `cne` substring → "cne" 3-char prefix 只 match 4 个真 cne_* op,安全。
