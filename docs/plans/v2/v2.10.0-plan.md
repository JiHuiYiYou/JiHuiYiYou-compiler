## Scope (~250 LOC + binary changes, 2 commits ship)

### A. `compiler/src0/main.jhyy` `run_qbe` 留空 stub (~30 行改)

**目的**: 移除 QBE 路径,纯走自写后端;留空 stub 占位方便 debug / 后期参考。

**实现**:
- `run_qbe(il_path, asm_path, t)` 函数体改成:
  - 立即 `jh_fputs_stderr("run_qbe: deprecated since v2.10.0, see changelog-v2.10.0.md; use codegen_amd64 path\n" as *u8);`
  - return -1 (fail,迫使 caller 切自写路径)
- `run_backend` 删除 QBE 分支:
  - 删 `if fb != (0 as *u8) { return run_qbe(...); }` (QBE_FALLBACK env var 路径)
  - 删 `return run_qbe(...)` fallback (sysv stub + unknown 分支)
  - 保留 `if mode == BACKEND_SELF() { ... codegen_amd64_run(...) ... }` + 自动降级 (但降级路径不再降 QBE,而是 fatal + stderr 报错)
- **不**完全删 `run_qbe` 函数 (留 W-XXX workaround 占位 + ABI 兼容);调走 → warning + return -1

**Edge case**:
- `QBE_FALLBACK=1` env var 读到 → 立即 `jh_fputs_stderr` warning + 忽略 (不进 QBE 路径)
- 自写 `codegen_amd64_run` fail → fatal + stderr 报错 (no fallback)

## Risk + rollback

**Risk 1**: QBE 移除后任何 codegen bug 没有 QBE 兜底 → regress 退步
- **Mitigation**: v2.9.0 已 ship verification harness (N=3 fixed point + cap_test 跨代);v2.10.0 启动前再跑 v2.9.0 ship gate;`run_qbe` 留空 stub 方便 debug (临时 `git revert` 切回 QBE 路径 — 不推荐,regress 链会断)
- **Rollback**: revert Commit 1 + Commit 2;回归 QBE 路径 active 状态

**Risk 2**: `qbe.exe` 删除触发 git 历史不可逆操作
- **Mitigation**: qbe.exe 是 gitignored (per `feedback_no_artifacts_in_project`);实际只 `rm -f` 本地 file;git tree 中如果曾 tracked 需 `git rm` → 这是正常操作,不可逆风险低
- **Rollback**: qbe.exe 历史 binary 不在 git tree (gitignored),无法恢复;但 git history 中 v2.10.0 commit 可 revert,rebuild qbe.exe 时从 vendor source 重新编译 (如有保留)

**Risk 3**: `run_qbe` 留空 stub + `QBE_FALLBACK` 移除触发回归测试 fail
- **Mitigation**: v2.8.0 ship 已 lock codegen_amd64 emit_mem/ctrl/peephole target_tag dispatch 全 target 覆盖;v2.10.0 启动前 regress.py 104/104 全过 + byte_equal_amd64 10/10 + 20/20 + D43 closure 持 hold
- **Rollback**: revert Commit 1;回归 `run_qbe` active + `QBE_FALLBACK` env var 路径

**Risk 4**: M5 启动阻塞 — v2.10.0 ship 后 user 未启动 M5
- **Mitigation**: v2.10.0 ship 通知 user M5 可启动;user 决定何时启动 M5 独立 sprint
- **Rollback**: N/A (M5 是 user 启动,非 v2.10.0 责任)
