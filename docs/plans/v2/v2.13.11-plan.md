## RCA (per `feedback_rca_first_root_cause`)

**Bug 1 — f32 swtof mis-emit**: `compiler/src0/codegen_amd64_emit_sse.jhyy emit_conv_swtof` (v2.11.19 ship) hardcode `cvtsi2sd + movsd`, 不查 `tok.qbe_type`。Fold IL `t6 =s swtof %t5` (qt = `=s`, 即 f32) 应 emit `cvtsi2ss + movss` (32-bit SSE); 实际 emit 64-bit f64 序列。结果: 下游 `t7 =s mul %t6, %t2` = `mulss` 拿 f64 bits 解释 = garbage, f32 swtof 后值 exit=7 而非 1。

**Bug 2 — 缺 `cltq`**: `emit_conv_swtof` emit `movl -src(%rbp), %eax` (32-bit load, GAS 自动 zero-extend %rax upper32 = 0) 后直接 `cvtsi2sd %rax, %xmm0`。`cvtsi2sd` 用 64-bit %rax, **但实际 %rax upper32 是上一次 %rax 的 stale bits** (因为 emit 序列里 `movabsq $imm, %rax` 然后 `movq %rax, stack` 等中间操作写过 %rax, 后续 movl 只清低 32-bit)。负数 i32 → %rax 高位全 1 → cvtsi2sd 解释为 huge negative → fold 路径走错 → 最终 exit=100 而非 99。

**Lexer + parse_and_emit 已完整 (无 gap)**: v2.11.19 已加 `stosi`/`dtosi`/`swtof`/`sltof`/`exts`/`extuw` lexer recognition (codegen_amd64_lexer.jhyy line 1418-1791, 8 函数, ~370 LOC) + parse_and_emit dispatch (codegen_amd64.jhyy line 123+);emit_conv_swtof 是唯一缺口。

**Plan agent 误诊"lexer gap"** (per `feedback_doc_refactor_factcheck`): Plan agent 报告 lexer 不识别 `stosi/dtosi/swtof`, 实际已识别 since v2.11.19。RCA 必须先 Read 工具验证 (per `feedback_rca_first_root_cause`), 不能想当然。

### 1. 修 `emit_conv_swtof` (per `compiler/src0/codegen_amd64_emit_sse.jhyy`)

```jhyy
// emit_conv_swtof — i32 (signed) → f32 / f64 via cvtsi2ss / cvtsi2sd
//   1. movl stack → %eax (32-bit load sign-extends to %rax by GAS)
//   2. cltq — sign-extend %eax → %rax (清零 upper 32-bit 至 sign-bit,
//      避免上一次 %rax 操作的 stale bits 影响 cvtsi2*)
//   3. cvtsi2ss / cvtsi2sd %rax, %xmm0 (cvtsi2* 用 %rax)
//   4. movss / movsd %xmm0 → stack slot
//
// v2.13.11 (W-083 真修): dst qt 由 tok.qbe_type 决定 (=s 走 cvtsi2ss + movss,
// =d 走 cvtsi2sd + movsd)。v2.11.19 之前 hardcode =d → f32 swtof silently emit
// f64 序列 → mulss/addss/subss 拿 f64 解释 = garbage, fmod_f32 exit=7 而非 1。
// W-058 fold fix 不需改 (QBE IL 仍 emit =s swtof), 此函数只需按 qt 走对指令 +
// 加 cltq sign-extension。

fn emit_conv_swtof(state: *u8, tok: *u8, target_tag: i32) -> i32 {
    let cg = state as *CGState;
    let s = (*cg).out;
    let arena = (*cg).arena;
    let t = tok as *ILToken;
    let dst_id = (*t).int_val;
    let src_id = cg_parse_temp((*t).text, (*t).text_len, 0 as i64);
    let dst_off = cg_offset_for_temp_with_target(dst_id, target_tag);
    let src_off = cg_offset_for_temp_with_target(src_id, target_tag);
    let is_f32: i32 = if (*t).qbe_type == QBE_S_LOCAL() { 1 as i32 } else { 0 as i32 };
    let cvt_suffix: *u8 = if is_f32 != (0 as i32) { "ss" as *u8 } else { "sd" as *u8 };
    let _r1 = sb_append_cstr(arena, s, "\tmovl " as *u8);
    let _r2 = sb_appendf_lld(arena, s, "%lld" as *u8, src_off);
    let _r3 = sb_append_cstr(arena, s, "(%rbp), %eax\n" as *u8);
    // W-083 v2.13.11: cltq (sign-extend %eax → %rax) 在 movl 之後, cvtsi2ss/sd 之前 —
    // 清零 upper 32-bit 至 sign-bit, 避免上一次 %rax 操作的 stale bits 影响 cvtsi2*。
    let _cltq = sb_append_cstr(arena, s, "\tcltq\n" as *u8);
    let _r4 = sb_append_cstr(arena, s, "\tcvtsi2" as *u8);
    let _r5 = sb_append_cstr(arena, s, cvt_suffix);
    let _r6 = sb_append_cstr(arena, s, " %rax, %xmm0\n" as *u8);
    let _r7 = sb_append_cstr(arena, s, "\tmov" as *u8);
    let _r8 = sb_append_cstr(arena, s, cvt_suffix);
    let _r9 = sb_append_cstr(arena, s, " %xmm0, " as *u8);
    let _r10 = sb_appendf_lld(arena, s, "%lld" as *u8, dst_off);
    let _r11 = sb_append_cstr(arena, s, "(%rbp)\n" as *u8);
    return 0;
}
```
