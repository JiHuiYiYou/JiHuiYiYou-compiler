## Scope (~800 LOC + toolchain 验证, 4 commits ship)

### A. 真 XMM regalloc (~250 LOC, NEW file `compiler/src0/codegen_amd64_regalloc.jhyy`)

**结构**:
- `XmmRegAllocator` struct: 包含 free list, in-use list, callee-saved bitmask, dirty list (需保存)
- `alloc_xmm()`: 返 free XMM id (优先 caller-save XMM0-XMM5;若 all in-use → spill lowest-priority)
- `free_xmm(id)`: 标 free + 持久化 caller-save 标记
- `spill_xmm(state, id, off)`: `movsd %xmmN, -<off>(%rbp)`
- `reload_xmm(state, id, off)`: `movsd -<off>(%rbp), %xmmN`
- `save_callee_saved_at_entry(state)`: 扫 in-use XMM6-XMM15 → `sub $8*N, %rsp; movsd %xmmN, -<8*N+...>(%rsp)`
- `restore_callee_saved_at_exit(state)`: 反向 restore
- `save_caller_saved_across_call(state, used_xmms)`: call 前 save,call 后 reload

**API 替换**: `compiler/src0/codegen_amd64_emit_call.jhyy` 的 XMM 临时分配调用 `alloc_xmm()` (替换原简单 "local XMM per-arg" 逻辑)。

### B. 真 amd64_sysv codegen 全覆盖 (~300 LOC, modify `compiler/src0/codegen_amd64_emit_*.jhyy`)

**Per `v2.x-qbe-rewrite.md § 3.1` + SysV ABI**:
- `codegen_amd64_emit_call.jhyy`: arg passing 按 SysV classification (INTEGER/MEMORY/SSE) + mixed interleaving
- `codegen_amd64_emit_mem.jhyy`: large struct return sret (RDI 隐式 first arg,if return type > 16 bytes)
- `codegen_amd64_emit_abi.jhyy` (NEW ~150 LOC): SysV-specific ABI helpers (classification + sret + vararg AL save)
- `target_dispatch.jhyy`: 加 `amd64_sysv` target_tag → 真 codegen path (替换 current "go QBE fallback for sysv")
- regress 全 119 test 跑 `JHY_TARGET=amd64_sysv python regress.py` (docker gcc:12) 验证 119/119 PASS
