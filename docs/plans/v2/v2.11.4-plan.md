## T4-b 真修 implementation (~30 LOC)

`emit_binop` 旧 hardcode (line 899-902):
```jhyy
let src1_id: i64 = 1 as i64;
let src2_id: i64 = 2 as i64;
let src1_off = cg_offset_for_temp_with_target(src1_id, target_tag);
let src2_off = cg_offset_for_temp_with_target(src2_id, target_tag);
```

**新** (parse op_text 拿真实 src1/src2):

```jhyy
// v2.11.4 (W-074.7 T4-b 真修): parse src2 from op_text。
let mut src2_is_imm: i32 = 0 as i32;
let mut src2_imm_val: i64 = 0 as i64;
let mut src2_id_parsed: i64 = -(1 as i64);
let mut src1_id_parsed: i64 = -(1 as i64);
let mut _comma_off: i64 = -(1 as i64);
if op_text != (0 as *u8) && op_text_len > (0 as i64) {
    src1_id_parsed = cg_parse_temp(op_text, op_text_len, 0 as i64);  // 第 1 个 %tN = src1
    _comma_off = cg_find_byte(op_text, op_text_len, 44 as i32, 0 as i64);  // ','
    if _comma_off >= (0 as i64) {
        // skip ws after comma → first char of src2
        if _fc == 37 {  // '%tN' temp
            src2_id_parsed = cg_parse_temp(op_text, op_text_len, 1 as i64);  // 第 2 个 %tN = src2
        } else if cg_is_digit(_fc) != 0 {  // digit literal imm
            src2_is_imm = 1;
            src2_imm_val = cg_parse_int_from(op_text, op_text_len, _si);
        }
    }
}
let src1_id = if src1_id_parsed >= 0 { src1_id_parsed } else { 1 };
let src2_id = if src2_id_parsed >= 0 { src2_id_parsed } else { 2 };
```

7 个 op emit 分支 (sub/mul/div/mod/cslt-w-cnew-w/add-fallback) 加 `src2_is_imm` branching, imm path emit `$<imm>, %<reg>` 替代 `-<off>(%rbp), %<reg>`。

`cg_find_byte` 新 helper (state.jhyy, ~12 LOC): scan text[from..len] 找 byte `c`, return offset 或 -1。
