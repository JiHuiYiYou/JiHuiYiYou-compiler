## Risk + rollback

**Risk 1**: Linux ELF runtime 不 bootstrap(链接错误 / 段对不齐 / _start 错位)— 镜像 v2.4.0 `runtime/uefi/` 已 ship OVMF 5/5 PASS 模式,模型验证。
- **Mitigation**:Phase 1 ship gate 4/4 verify;hello.elf readelf verify。
- **Rollback**:revert Phase 1 commit。`runtime/linux_elf/` 整段删;v2.7.0 emit_call refactor 不受影响。

**Risk 2**: regress.py `--cross` wire 在 Windows host 无 WSL/Docker 时 fallthrough 错误。
- **Mitigation**:Phase 2 ship gate 3/3 verify 显式测 `--cross=none` + `--cross=auto` (无 wsl/Docker) → SKIP exit 0。
- **Rollback**:revert Phase 2 commit。

**Risk 3**: D43 re-baseline 让旧 `92e82554...` 失效 → 后续 audit 找不到。
- **Mitigation**:per `feedback_changelog_umbrella` + `feedback_audit_single_commit_diff`,新 baseline ship 时**强制**写 `docs/logs/v2/d43-baseline-archive.md` 存档旧 baseline + commit message 引用。
- **Rollback**:revert Phase 3 commit;但旧 baseline 已 archive 进 docs (即使 code revert,history 仍可查)。

**Risk 4**: jhyy main_jhyy 跟 W-065 cmd_run pre-check 的 `_jhyy_main` wrapper convention 不一致 — v1.8.3.2 时 `main_jhyy` 是 jhyy program main fn 名字,cmd_run 显式检查。
- **Mitigation**:crt0.S `call main_jhyy` 而非 `call main`,跟 W-065 cmd_run pre-check 一致 (per `compiler/src0/driver.jhyy` line N pre-check)。
- **Rollback**:revert Phase 1 + crt0.S 改名;emit_call refactor (v2.7.0) 不受影响。
