## Risk + rollback

**Risk 1** (Phase 1a): `--no-link` flag 不慎影响 Win target behavior。
- **Mitigation**: 默认行为完全不变 (flag opt-in);Win path `if no_link == 0` 保持 link;byte_equal_amd64.sh 10/10 gate catch 任何漂移。
- **Rollback**: revert Commit 1。

**Risk 2** (Phase 1b): regress.py docker branch 改 2-stage subprocess 后 5 sysv tests FAIL。
- **Mitigation**: v2.7.1 ship 已 post-ship verify crt0.S + link.ld + 手写 .s 跑通 (`hello from Linux ELF` exit 42);jhyy 产 .s 跟手写 .s 都 emit `_start → main_jhyy → exit` 相同 pattern。
- **Rollback**: revert Commit 1; 回归 wire-only SKIP status。

**Risk 3** (Phase 1b): `MSYS_NO_PATHCONV=1` env var 在 subprocess.run 不可靠传递。
- **Mitigation**: 显式 `env={**os.environ, "MSYS_NO_PATHCONV": "1"}` 参数。
- **Rollback**: 改回 absolute path escape 法。

**Risk 4** (Phase 1c): 5 sysv tests 中某些 expected exit code 不是 0。
- **Mitigation**: v2.8.3 ship gate 接受 `passed (exit=N)` 即可;user 可手验 exit code 跟 expected 一致。
- **Rollback**: 不影响 Commit 1 ship。

**Risk 5** (Phase 1b, scope creep): `_DOCKER_BIN` + `_resolve_docker_bin()` 加到 regress.py — 影响 _resolve_cross_mode behavior (minor: 加 fallback path list)。
- **Mitigation**: fallback list 是 additive (不减少现有 functionality);已知 docker Desktop path 是 stable (per Docker Desktop 4.84.0 install)。
- **Rollback**: revert Commit 1。
