## Sprint 1: target dispatcher

### 1.1 范围

#### 1.1.1 Target 数据结构
- `compiler/src0/target/target_dispatch.jhyy`（新）：
  - `enum Target { Amd64Win, Amd64WinFreestanding, Amd64SysvStub }`
  - `fn target_parse(s: [*]u8) -> Target`：解析 `--target=<triple>` 字符串
  - `fn target_default() -> Target`：默认 `Amd64Win`（保持 v1.x 兼容）
  - `fn target_name(t: Target) -> [*]u8`：返回三元组字符串

```jhyy
// compiler/src0/target/target_dispatch.jhyy

type Target = enum {
    Amd64Win,                    // x86_64-w64-mingw32 / MS x64 + link ucrt
    Amd64WinFreestanding,        // x86_64-w64-none / MS x64 + 不 link libc (UEFI)
    Amd64SysvStub,               // x86_64-linux-none (预留, v2.x 中期 M2 实现)
}

fn target_parse(s: [*]u8) -> Target {
    if (eq(s, "amd64_win")) { return Target::Amd64Win; }
    if (eq(s, "amd64_win_freestanding")) { return Target::Amd64WinFreestanding; }
    if (eq(s, "amd64_sysv")) { return Target::Amd64SysvStub; }
    fatal("unknown target '%s', available: amd64_win, amd64_win_freestanding (amd64_sysv in v2.x M2)");
}

fn target_default() -> Target {
    return Target::Amd64Win;
}

fn target_name(t: Target) -> [*]u8 {
    switch t {
        case Target::Amd64Win => return "amd64_win",
        case Target::Amd64WinFreestanding => return "amd64_win_freestanding",
        case Target::Amd64SysvStub => return "amd64_sysv",
    }
}
```

#### 1.1.3 CLI flag
- `compiler/src0/main.jhyy`（改）：
  - 解析 `--target=<triple>` 参数
  - 调用 `codegen_module(m, target, ir)`
  - 默认 target = `Amd64Win`
  - 未知 target → `target_parse` 内部 fatal（见 1.1.1）

```jhyy
// compiler/src0/main.jhyy (改)

fn main(argc: i32, argv: [*][*]u8) -> i32 {
    let target = target_default();  // Amd64Win
    let input_path = "";
    let output_path = "a.out";

    // 解析 CLI args
    let i = 1;
    while (i < argc) {
        let arg = argv[i];
        if (starts_with(arg, "--target=")) {
            target = target_parse(arg + 9);  // 跳过 "--target="
        } else if (starts_with(arg, "-o")) {
            output_path = arg + 3;
        } else {
            input_path = arg;
        }
        i = i + 1;
    }

    // 调用 codegen + target dispatcher
    let ir = ir_new();
    let m = parse_module(input_path);
    codegen_module(m, target, ir);
    ir_write_file(ir, output_path);
    return 0;
}
```

### 1.3 验收
1. **编译验证**: `jhyy --target=amd64_win hello.jhyy` 走 `Amd64Win` 路径（行为跟 v1.x 一致）
2. **未知 target 报错**: `jhyy --target=amd64_unknown hello.jhyy` → fatal "unknown target 'amd64_unknown'"
3. **目标可解析**: `target_parse("amd64_win_freestanding")` 返回 `Amd64WinFreestanding`
4. **freestanding stub 报错**: `jhyy --target=amd64_win_freestanding hello.jhyy` → fatal "ABI 抽离在 v2.1.0 实现"（明确指向下一版本）
5. **sysv stub 报错**: `jhyy --target=amd64_sysv hello.jhyy` → fatal "实现留 v2.x M2"
6. **回归验证**: `regress.py` 持平 v1.0 baseline (50/53 PASS, 0 failed, 3 skipped)

### 1.4 风险
- **codegen target 分支是大改动**: Sprint 1 第一步保留 `Amd64Win` 完整路径不变（纯重构加 switch 占位），不影响行为
- **默认 target 改 Amd64Win 是 P0**: 不能破坏 v1.x 兼容行为，所有现有 regress 测试必须通过
- **enum 命名 vs ABI 抽离顺序**: Target enum 包含 `Amd64WinFreestanding` 是占位，真实 ABI 抽离在 v2.1.0；enum 命名提前避免 v2.1.0 改动枚举顺序
