## Scope (~200 LOC, 1 commit ship)

### A. `compiler/tests/bootstrap/fixed_point.sh` (NEW, ~100 行)

**目的**: N=3 selfhost closure 验算,产出 `.il` byte-equal 比对。

**实现**:
- 准备 3 份 jhyy binary:
  - `jhyy_v1.exe.exe` — v1 baseline frozen, sha `51376ce5...`(v2.4.0 ship 时 freeze,checkout 即可)
  - `jhyy_v2.exe` — v2.9.0 编出 (jhyy_v1 编 src0/main.jhyy)
  - `jhyy_v3.exe` — v2.9.0 编出 (jhyy_v2 编 src0/main.jhyy)
- N=3 验算:
  - `jhyy_v1.exe.exe compile compiler/src0/main.jhyy -o /tmp/_v1.il`
  - `jhyy_v2.exe compile compiler/src0/main.jhyy -o /tmp/_v2.il`
  - `jhyy_v3.exe compile compiler/src0/main.jhyy -o /tmp/_v3.il`
  - `diff /tmp/_v1.il /tmp/_v2.il && diff /tmp/_v2.il /tmp/_v3.il` → 0 差异 = N=3 ✅
- 试 N=4: N=3 + `jhyy_v4.exe` (jhyy_v3 编出) → byte-equal ↔ v3
- 试 N=5: N=4 + `jhyy_v5.exe` (jhyy_v4 编出) → byte-equal ↔ v4
- 输出: stdout 打 N=3/4/5 + sha256 链 + 通过/失败;exit code 0 = pass

**Edge case**:
- 任意 v_N 编 src0/main.jhyy fail → 立即 exit 1 + 打 stderr (per `feedback_fix_evaluation_rule`)
- `.il` 不 byte-equal → 立即 exit 1 + 打 diff (per `feedback_fix_evaluation_rule`)
- `jhyy_v1.exe.exe` 不存在 → 友好提示"run `git checkout archive/v2.4.0 -- compiler/build/bin/jhyy_v1.exe.exe` 恢复 v1 baseline"

## Risk + rollback

**Risk 1**: fixed_point.sh N=3/4/5 跨代 .il 不 byte-equal (codegen 漂移)
- **Mitigation**: v2.8.0 ship 已 lock codegen_amd64 emit_mem/ctrl/peephole target_tag dispatch,v2.8.1/2/3 ship gate 持 byte_equal hold;v2.9.0 不动 codegen → N=3 应 hold
- **Rollback**: revert Commit 1;回归无 verification harness 状态 (无功能损失)

**Risk 2**: cap_test.jhyy V3-C ship 后跨代 borrow check 不一致
- **Mitigation**: v3.1.0 ship 已 verify cap_test 跨 v3.x 代一致;v2.9.0 跨 v1/v2/v3 一致性是 V3-C 后的隐含 invariant
- **Rollback**: 不影响 Commit 1 ship;cap_test FAIL 是 v3.x bug,推回 v3 axis owner

**Risk 3**: jhyy_v1.exe.exe 不存在 (误删 v1 baseline)
- **Mitigation**: v2.4.0 ship 时 freeze sha `51376ce5...` 在 git history;`git checkout archive/v2.4.0 -- compiler/build/bin/jhyy_v1.exe.exe` 恢复
- **Rollback**: 不影响 Commit 1;v1 baseline 恢复是 setup 问题,非 code 问题

**Risk 4**: N=4/N=5 byte-equal fail (informational)
- **Mitigation**: N=3 是 ship gate;N=4/5 是 bonus,失败仅 informational,不阻塞
- **Rollback**: N/A (informational,无 ship gate 关联)
