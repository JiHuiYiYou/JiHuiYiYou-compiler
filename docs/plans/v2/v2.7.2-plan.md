## Phase 1: 修 false-positive + 改 docker image (1 commit)

### 1a. `compiler/build/bin/regress.py` `_run_cross_env_sysv_test`

**当前 (line 213-227)**:
```python
try:
    r = subprocess.run(
        cmd, capture_output=True, text=True, timeout=timeout,
        encoding="utf-8", errors="replace",
    )
    output = (r.stdout or "") + (r.stderr or "")
    if r.returncode == 0 and "EXIT:" in output:
        # parse EXIT:N from output
        for line in reversed(output.splitlines()):
            if line.startswith("EXIT:"):
                exit_code = int(line[len("EXIT:"):].strip())
                return (True, f"passed (exit={exit_code}, cross={cross_mode})")
        return (True, f"passed (cross={cross_mode})")
    return (False, f"failed (exit={r.returncode}, cross={cross_mode}): "
                   f"{output[-200:]}")
```

**新 (false-positive 修 + 显式 ELF 检查)**:
```python
try:
    r = subprocess.run(
        cmd, capture_output=True, text=True, timeout=timeout,
        encoding="utf-8", errors="replace",
    )
    output = (r.stdout or "") + (r.stderr or "")
    # Parse EXIT:N from output
    exit_code = None
    for line in reversed(output.splitlines()):
        if line.startswith("EXIT:"):
            try:
                exit_code = int(line[len("EXIT:"):].strip())
            except ValueError:
                pass
            break
    if r.returncode != 0:
        return (False, f"failed (cmd exit={r.returncode}, cross={cross_mode}): "
                       f"{output[-200:]}")
    if exit_code is None:
        return (False, f"failed (no EXIT: marker, cross={cross_mode}): "
                       f"{output[-200:]}")
    # exit=127 = "command not found" in Linux (e.g. /tmp/_cross_sysv.elf not built
    # because gcc missing in container, or compile step failed silently).
    # Only count exit_code==127 as actually-runnable test failure if the .elf
    # was produced; otherwise treat as infra error.
    if exit_code == 127:
        # Check stderr/stdout for "No such file" or "gcc: not found" hint
        if "not found" in output.lower() or "no such file" in output.lower():
            return (False, f"failed (binary not built, cross={cross_mode}): "
                           f"check gcc in container (use gcc:12 not ubuntu:22.04) — "
                           f"{output[-200:]}")
        return (False, f"failed (exit=127, cross={cross_mode}): "
                       f"{output[-200:]}")
    return (True, f"passed (exit={exit_code}, cross={cross_mode})")
```

**关键 invariant**:
- 之前: exit=127 被报 "passed (exit=127)" — 假阳性
- 之后: exit=127 显式检查 `not found` hint → 报 "failed (binary not built, ...)"
- 真正跑通: exit_code 是测试期望值 (e.g. 35 for sysv_struct_pass) → "passed (exit=35)"

### 1b. Docker image 改 `ubuntu:22.04 → gcc:12`

**当前 (line 214)**:
```python
elif cross_mode == "docker":
    cmd = [
        "docker", "run", "--rm",
        ...
        "ubuntu:22.04", "bash", "-c",
```

**新**:
```python
elif cross_mode == "docker":
    cmd = [
        "docker", "run", "--rm",
        ...
        "gcc:12", "bash", "-c",
```

**Why**: `ubuntu:22.04` 镜像无 `gcc`(`gcc not found` 报 exit=127);`gcc:12` 镜像预装 gcc 12.5.0(per v2.7.1 post-ship verify `gcc --version` 输出)。
