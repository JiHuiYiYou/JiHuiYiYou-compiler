**v2.15.0 实际工作** (per 2026-09-22 三个 Explore agent + Plan agent + user Strategy B+ decide):
- **架构观察** (`main.jhyy:692-704` `build_il`): codegen.jhyy 调 `ir_emit_*` (~390 call sites) 写 IL 文本到 `IRBuf.sb` (`*StringBuilder`) → `jh_fopen_wb(il_path)` → `fwrite(buf)` → `fclose`。**`.il` 文件是 round-trip 瓶颈** — self-backend (`codegen_amd64_run:251-288`) 立即再 `jh_read_file` 读回 → `lex_il` 重新 lex 文本 → `parse_and_emit` 写 `.s`。
- **`ILToken` struct 已存在** (`codegen_amd64_state.jhyy:86`): 40 B tagged union `{kind, text, text_len, int_val, qbe_type, line}`。self-backend 的 `lex_il` 已把它作为 first-class struct 喂给 `parse_and_emit` (`codegen_amd64.jhyy:338` 24-way dispatch)。
- **Strategy B+ (per user 2026-09-22 decide)**: 跳过 file I/O, 保留 IL 文本在内存(`IRBuf.sb` buffer), self-backend 直接吃 `(text, len)`;**不复用 `lex_il`** 的 0-byte / 字符串内 `}` 等 pre-existing 限制(这些是历史 lex 限制,不是 v2.15.0 引入;in-mem 跟 file path 都触发同样 6 个 unknown QBE IL mnemonic stderr warnings for src0/main.jhyy)。
- **QBE IL emit 不变**: 仍 emit IL 文本, 只是 in-mem 传递, 不写盘。

## Risk + rollback

**Risk 1**: in-mem path 与 file path 行为不同 (`lex_il` input 不一致)
- **Mitigation**: V.2 双路径对照测 (`216683e1...` byte-equal); 若 in-mem 回归 → rollback to file path via `JHY_WRITE_IL=1`
- **Rollback**: revert commit 1, 回到 v2.14.0; `JHY_WRITE_IL=0` 默认, 无副作用

**Risk 2**: `.s` baseline re-pin 期间 sha 漂移 >0.1%
- **Mitigation**: V.4 跑 3 次取收敛; 漂移 >0.1% → worktree 调查 codegen path 不同再 pin
- **Rollback**: 不写新 baseline, 保留 v2.14.0 `43fee332...` (.il only); `.s` byte-equal 推 v2.16.0

**Risk 3**: `ILToken[]` arena 640 KB 容量限制
- **Mitigation**: 现有 `lex_il` 已用 16384 slot, in-mem 路径 input 来自 `IRBuf.sb` 字符串长度; len > 640 KB → fail gracefully (lex_il 内部 bound check)
- **Rollback**: large file (eg. `big_test`) 临时走 `JHY_WRITE_IL=1`

**Risk 4**: `main.jhyy` W-068 fix #4 单元类型 cascade
- **Mitigation**: if/else 分支都加显式 assignment (`let _e = ...; did_inmem = 0;`)
- **Rollback**: 走 std pattern; if/else 单元 → () 类型对齐

**Risk 5**: 1 commit 涵盖 src0 + docs + scripts 触发 audit complexity
- **Mitigation**: commit message 明确分段 (src0 in-mem entry / scripts .s byte-equal / docs)
- **Rollback**: revert 1 commit 完整回到 v2.14.0
