## Honest discovery mid-implementation (修正 v2.8.1 plan 假设)

**v2.8.1 plan Phase 1 ship gate 验证时发现**:

CLI smoke test:
```bash
jhyy.exe compile --target=amd64_sysv_freestanding foo.jhyy -o /tmp/_test
# 实际:fatal "amd64_sysv_freestanding target: 实现留 v2.7.1"
# 在 [4b-FAIL] cg_module fatal 阶段
```

**Root cause**: jhyy-side `compiler/src0/codegen.jhyy` `cg_module` 函数仍 v2.7.0 stub-fatal:
- line 3880: `amd64_sysv target: emit_call 拆 Win/SysV 已 wire (Phase 2b); cg_module 全 dispatch 留 v2.7.1` → `return 0`
- line 3885: `amd64_sysv_freestanding target: 实现留 v2.7.1` → `return 0`

**Flow**:
```
cmd_compile (main.jhyy)
  → cg_module (codegen.jhyy)        ← unconditional, 总是 emit QBE IL
    → if target_tag==SYSV/SYSVFS: fatal "实现留 v2.7.1" (return 0)
  → run_backend (main.jhyy)
    → target_backend_mode + JHY_SELF_BACKEND env gate
    → codegen_amd64_run (or run_qbe → QBE)
```

所以 **即使** JHY_SELF_BACKEND=1 + codegen_amd64_run 真 emit 4 targets (v2.8.0 ship),jhyy.exe 在 `cg_module` 阶段就 fatal 了。codegen_amd64_run 不会被调到。

**修正 v2.8.1 plan scope claim**: WSL branch 5 sysv tests PASS **不**由 v2.8.1 实现。真正的 unblock 要修 jhyy-side `codegen.jhyy cg_module` (v2.7.0 Phase 2b 漏做的活) — 这是 **driver-only patch** scope 之外的工作,留 v2.8.2 / v2.x 末。

## Discovery: new limitation (filed W-XXX)

**W-070** (NEW): `jhyy.exe --target=amd64_sysv_freestanding foo.jhyy` 在 `cg_module` (codegen.jhyy) 阶段 fatal — v2.7.0 Phase 2b 漏做的活。

**Bypass**: 当前 (post-v2.8.1 ship) 唯一 production-ready SysV codegen 路径 = QBE:
```
jhyy.exe compile --target=amd64_sysv_freestanding foo.jhyy
```
仍 fatal (codegen.jhyy cg_module)。SysV 真 codegen **实际可达** path = run QBE on Win IL? No, QBE only takes IL input — `.il` produced by cg_module must succeed first.

**真 fix scope** (v2.8.2 或 v2.x 末):
1. 修 `compiler/src0/codegen.jhyy` `cg_module`:
   - SYSV case: 调 `abi_amd64_sysv.jhyy` 模块 emit SysV QBE IL (跟 abi_win emit 类似但用 SysV ABI)
   - SYSV_FREESTANDING case: 调 `abi_amd64_sysv_freestanding.jhyy` 模块
2. v2.7.0 ship 的 abi_amd64_sysv*.jhyy 7 ABI fn 是 QBE-call-time helper (emit_function_header 等),不是 cg_module-time QBE IL emitter → 需要扩 module 加 cg_module-time emit fn
3. Regress 5 sysv tests 真跑 PASS 验证

**OS 启动链路**: W-070 = M4 launch 硬前置 (per `v2.0.0-os-prep.md` § 1 M4 需要 amd64_sysv 真能用)。**v2.8.1 不** close M4 硬前置 — `v2.8.2` (or v2.x 末) 才是。

## Risk + rollback

**Risk 1** (Phase 1): C-side `target_dispatch.h` enum rename STUB → SYSV 触发 cross-side byte-equal invariant 漂移(jhyy-side `TARGET_AMD64_SYSV()` 已 return 2 as i32, C-side enum 值 `=2` 保持 → invariant 锁 OK)。
- **Mitigation**: rename 仅改名字,enum 数值 `=2` 不动。
- **Rollback**: revert Commit 1。

**Risk 2** (Phase 1): C-side `cg_module` 加 SYSV_FREESTANDING case 漂移 Win ABI byte-equal。
- **Mitigation**: switch case 顺序不变 + 默认 fall-through 行为不变 → byte_equal_amd64.sh `--baseline` 20 PASS 任何漂移立即 catch。
- **Rollback**: revert Commit 1。
