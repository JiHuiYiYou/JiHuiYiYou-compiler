## Implementation summary

### Phase 1 — emit_load flag propagate (RC-1, ~5 LOC)

**File**: `compiler/src0/codegen_amd64_emit_mem.jhyy`

emit_load 已有 indirect dispatch (line 689: `if cg_is_address_holder(state, src) != (0 as i32)`),但 emit 完后**不**对 dst 调用 `cg_record_temp_holds_address`。后续 `add dst, imm` 看不到 flag → `loadw <result>` 走 slot read 路径 → wrong value。

Fix: emit_load 函数末尾 (line 651 之前) 加:
```jhyy
if (*t).qbe_type == QBE_L_LOCAL() && cg_is_address_holder(state, src) != (0 as i32) {
    let _lp = cg_record_temp_holds_address(state, dst);
}
```

守卫双条件: (a) qbe_type == QBE_L_LOCAL (i32/w load 不 flag), (b) src 是 address-holder (R7 反向测试)。

### Phase 2 — emit_copy LABEL flag propagate (RC-1, ~5 LOC)

**File**: `compiler/src0/codegen_amd64_emit_call.jhyy`

emit_copy LABEL 分支 emit `leaq <label>(%rip), %rax; mov<size> %rax, -dst(%rbp)` 然后 `return 0;` (line 1168)。**完全跳过** line 1225 FNARG path + line 1260 TEMP path 的 flag propagate。后续 `add dst, imm; loadw <result>` 看不到 flag。

Fix: line 1168 `return 0;` 之前加:
```jhyy
if dst_qt == QBE_L_LOCAL() {
    let _la = cg_record_temp_holds_address(state, dst_id);
}
```

守卫: dst_qt == QBE_L_LOCAL 才 flag (per codegen_amd64.jhyy:1035-1043 "copy $X" 全 QBE_L)。

### Phase 3 — W-017 module-level `let mut` 真修 (RC-3, ~40 LOC)

**File**: `compiler/src0/codegen_amd64_emit_mem.jhyy` (新加 emit_load $label + emit_store $label paths)

module-level `let mut g_X: T = init` 之前走 C-side `jhyy_helpers.c` runtime write-back,C-side freeze 后 jhyy-side 必须 emit 完整路径:
- codegen.jhyy emit `data $g_x = { w 41 }` data 段 (已存在)
- emit_load 加 `$label` path: `mov<size> <label>(%rip), %<reg>; mov<size> %<reg>, -<dst>(%rbp)` 
- emit_store 加 `$label` path: `mov<size> -<src>(%rbp), %<reg>; mov<size> %<reg>, <label>(%rip)`

(RIP-relative LEA/store 位置无关,Win/SysV 双 ABI 通用。)

### Phase 4 — RC-4 match range cmp+clamp fix (RC-4, ~30 LOC)

**File**: `compiler/src0/codegen_amd64_emit_ctrl.jhyy` (match dispatch)

match `1..10` / `-3..-1` 范围模式:
- (a) 负数 IMM 解析 bug:`-3` lex 出 token 后负号被吞掉,parse 出 `3` 而非 `-3`,clamp 范围错
- (b) clamp fix:低边界和高边界用 i64 sign-aware 比较,不要 mod 2^32
