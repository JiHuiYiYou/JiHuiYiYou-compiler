## Stage 1: abi-v1.0.0 § 13 增补

### 1.1 范围

#### 1.1.1 § 13.1 Target 三元组
- `docs/abis/jhyy-abi-v1.0.0.md` 增 § 13.1：
  - Target 三元组表（per Linux 三元组习惯：arch-vendor-os-environment）
  - amd64_win / amd64_win_freestanding / amd64_sysv (v2.x M2 预留)

#### 1.1.2 § 13.2 多 target ABI 差异表
- `docs/abis/jhyy-abi-v1.0.0.md` 增 § 13.2：

| 维度 | amd64_win | amd64_win_freestanding | amd64_sysv (预留 v2.x M2) |
|------|-----------|------------------------|---------------------------|
| 参数寄存器 | rcx/rdx/r8/r9 (4) | rcx/rdx/r8/r9 (4) | rdi/rsi/rdx/rcx/r8/r9 (6) |
| shadow space | 32 字节 | 32 字节 | 0 |
| 是否 link ucrt | ✅ | ❌ | ❌ (n/a) |
| 是否 link vcruntime | ✅ | ❌ | ❌ |
| 是否 link glibc/musl | ❌ | ❌ | ✅ (hosted) / ❌ (freestanding) |
| 函数 entry | `main` (CRT 调) | 用户写 `efi_main` / `_start` | 用户写 `main` (libc 调) / `_start` (freestanding) |
| struct pass-by-value | per v0.4 ABI | per v0.4 ABI | per v0.4 ABI (类 SysV) |
| 寄存器返回值 | rax | rax | rax |

#### 1.1.3 § 13.3 freestanding 约定
- `docs/abis/jhyy-abi-v1.0.0.md` 增 § 13.3：
  - 用户必须自己写 `efi_main` (UEFI) 或 `_start` (裸机) entry point
  - jhyy runtime **不在** freestanding binary 里（无 `memcpy` / `memset` / `malloc` 等 libc 桥）
  - 不 link ucrt / vcruntime / libc / glibc / musl
  - 外部函数调用按 ABI 走（MS x64 for amd64_win_freestanding, SysV for amd64_sysv_freestanding）
  - 数据段 `.data` / `.bss` 走 QBE 默认，无 prefix
  - 函数符号无 `_` prefix（vs MSVC `_main` 风格，jhyy 编 Windows hosted 也无 prefix）

#### 1.1.4 § 13.4 UEFI 跟 Windows x64 ABI 对齐（per D-GUI-12）
- `docs/abis/jhyy-abi-v1.0.0.md` 增 § 13.4：
  - UEFI 调用约定 = EFIAPI = MS x64（per `feedback_uefi_x64_conventions`）
  - 4 参数寄存器 rcx/rdx/r8/r9
  - shadow space 32 字节
  - struct pass-by-value per v0.4 ABI

#### 1.1.5 § 13.5 跟 jhyy_OS 端 ABI 对齐（per `coordination.md § 0`）
- `docs/abis/jhyy-abi-v1.0.0.md` 增 § 13.5：
  - v2.0 期间定基础 ABI（§ 13.1-13.4）
  - M1 启动前跟 jhyy_OS 端 cross-check 详细 ABI（struct layout / calling convention）
  - 跨边界 Q-OS-001~009 已全闭环，v2.0 不引入新 cross-boundary 问题

### 1.2 依赖
- v2.1.0 ✅ shipped（ABI 抽离完成 + 单元测试通过）

### 1.3 验收
1. **§ 13 增补完成**: `docs/abis/jhyy-abi-v1.0.0.md` § 13 增补 + git commit + review pass
2. **§ 13 跟 v2.1.0 ABI 实现一致**: § 13.2 ABI 差异表跟 `abi_amd64_win.jhyy` + `abi_amd64_win_freestanding.jhyy` 实现一致
3. **跨边界决策引用**: § 13.5 引用 D-GUI-12 / D1 / D40 / D41 / D43

### 1.4 风险
- **spec § 13 跟 jhyy_OS 端冲突**: Stage 1 末 cross-check `coordination.md § 0` + jhyy_OS 设计文档；冲突走 Q-OS-XXX 流程

  - 用户必须自己写 `efi_main` / `_start` entry point
  - 不引用 jhyy runtime helper（memcpy / memset / malloc）
  - **v2.0 期间仅定约定，不实施新语法**

- `docs/abis/jhyy-lang-spec-v1.3.0.md` 增 § 20：
