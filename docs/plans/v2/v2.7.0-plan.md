## Phase 2: emit_call refactor + SysV body wire (Phase 2 commit)

### 2a. Split arg-reg helper in `codegen_amd64_emit_call.jhyy`

- if target == Win OR WinFS: 4 regs rcx/rdx/r8/r9 + subq $32,%rsp
- if target == SysV OR SysVFS: 6 regs rdi/rsi/rdx/rcx/r8/r9 + no shadow

line 251 `subq $32, %rsp` + line 261 `addq $32, %rsp` 都改 gated。Pass target tag from caller through emit_call stack (新增 parameter)。

## Risk + rollback

**Phase 1 风险**:
- **Risk 1**: ABI module import path — jhyy import 是 flat (`compiler/src0/abi_amd64_win.jhyy:7-9`),新 modules follow same convention。`cg_module` call `target_abi_module(t)` + `import` may fail if module name 不 match。
  - **Mitigation**:Phase 1 不 wire to codegen,纯 module load + classify_arg unit test → codegen path 不动。
  - **Rollback**:revert Phase 1 commit (no ABI wired to codegen yet)。
- **Risk 2**: `_STUB` rename 误改 C-side enum 锁 — `_STUB` rename body 必须 `return 2 as i32` 不变。
  - **Mitigation**:rename only `fn` name,body `return 2 as i32` 保留。`target_dispatch.jhyy:14-15` doc 已经说"tag value 跟 C-side enum byte-equal 必须"。
  - **Rollback**:revert 即可。

**Phase 2 风险**:
- **Risk 3**: emit_call refactor 破坏 Win byte-equal — refactor 必须保持 Win 4-reg + 32B shadow 路径 byte-equal to v2.6.7 baseline。
  - **Mitigation**:Phase 2 ship gate 要求 `byte_equal_amd64.sh --baseline` 20 PASS (10 byte-equal + 10 baseline match) — refactor 漂移立即 catch。
  - **Rollback**:revert Phase 2 commit。Win ABI 仍 works (Phase 1 留下完整 ABI module skeleton,Phase 2 只 refactor emit_call split)。
- **Risk 4**: `target_abi_module(t)` chokepoint miss call site — cg_module 内 1 处 call,但 codegen_amd64_run / codegen_amd64_state 可能也有 ABI-dependent emit。
  - **Mitigation**:Phase 2 ship gate 5/5 PASS,W-069-style e2e 验证 (jhyy.exe 编 main.jhyy 跑通 + regress 104/104)。
  - **Rollback**:revert Phase 2 commit。
