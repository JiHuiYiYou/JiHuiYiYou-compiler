## alloc-tracking 真修 implementation (~111 LOC)

### Edit 1: `compiler/src0/codegen_amd64_state.jhyy` (+89 LOC)

```jhyy
// CGState 加 temp_slot_for_id field
struct CGState {
    ...
    temp_slot_for_id: *u8,  // v2.11.5 alloc-tracking
    ...
}

// extern bridge (跟 regalloc jh_regalloc_get/set 同 pattern)
extern fn jh_cgstate_get_temp_slots() -> *u8;
extern fn jh_cgstate_set_temp_slots(p: *u8) -> i32;

fn cg_max_temp_slots() -> i64 { return 256 as i64; }  // 5x regress max safety margin

fn cg_state_set_temp_slots(state: *u8) -> i32 {
    let s = state as *CGState;
    let _ = jh_cgstate_set_temp_slots((*s).temp_slot_for_id);
    return 0 as i32;
}

fn cg_record_temp_slot(state: *u8, temp_id: i64, slot: i64) -> i32 {
    if temp_id < (0 as i64) || temp_id >= cg_max_temp_slots() { return 0 as i32; }
    let s = state as *CGState;
    if (*s).temp_slot_for_id == (0 as *u8) { return 0 as i32; }
    let p = ptr_add_u8((*s).temp_slot_for_id, temp_id * (8 as i64)) as *i64;
    *p = slot;
    return 0 as i32;
}
```

**Forward-ref fix**: 所有 v2.11.5 helpers 挪到 `cg_state_init` 之前 (否则 init call extern undefined)。

`cg_state_init` 改: arena alloc 256-entry i64 array + memset 0 + wire extern bridge (call `cg_state_set_temp_slots(state)`)。

`cg_state_reset_for_function` 改: per-fn zero slot array。

`cg_offset_for_temp` 改:
```jhyy
fn cg_offset_for_temp(t: i64) -> i64 {
    if t < (0 as i64) { return 0 as i64; }
    let slots = jh_cgstate_get_temp_slots();
    if slots != (0 as *u8) && t < cg_max_temp_slots() {
        let p = ptr_add_u8(slots, t * (8 as i64)) as *i64;
        let recorded = *p;
        if recorded != (0 as i64) { return recorded; }
    }
    let spill_off = regalloc_query_spill_off_no_arr(t);
    if spill_off != (0 as i64) { return spill_off; }
    return (0 as i64) - (32 as i64) - t * (8 as i64);
}
```

`cg_offset_for_temp_with_target` 同 pattern 改。

## Risk + rollback

**R1** — `temp_slot_for_id` arena alloc + memset in `cg_state_init` adds ~MAX_TEMP_SLOTS*8 = 2KB per compile。Negligible memory cost (compile-time only, freed at process exit)。

**R2** — `cg_offset_for_temp` lookup may return non-zero for temps that were never alloc'd (e.g. if arena memset skipped)。Mitigation: `!= 0` check distinguishes recorded from default; if memset 正确, default = 0, recorded = actual offset。

**R3** — `cg_record_temp_slot` out-of-bounds (temp_id ≥ MAX_TEMP_SLOTS=256)。Current regress tests max temp id 51 (nested_struct_deep)。256 is 5x safety margin。Bigger tests (big_test has hundreds of temps) may exceed — verify by running big_test on the new binary。If exceed, bump MAX_TEMP_SLOTS to 1024。

**R4** — `cg_record_temp_slot` 写入与 `cg_offset_for_temp` 读取之间可能 race in multi-threaded codegen — current codegen is single-threaded, no race。

**Rollback (any of R1-R4)**: revert Commit 1。All effects revert to v2.11.4 baseline。
