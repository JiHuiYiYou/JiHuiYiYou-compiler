1. ✅ **N≥10 fixed point closure (Win mingw)**:
   - `compiler/tests/bootstrap/fixed_point.sh` 跑 jhyy → jhyy_v1 → ... → jhyy_v10 编 `compiler/src0/main.jhyy`
   - 10 代产出 `.il` sha 必须 byte-equal (即 .il sha `e6b6f1fa...` 不变)

   - `compiler/tests/bootstrap/mutation_test.py` (NEW) 实现 mutation injection framework
   - 30 个 mutation 在 src0/main.jhyy 注入, 按类目分组:
     - 5 个 ABI mutation (改 struct field offset / 改 calling convention flag / 改 type tag bit pattern)
     - 10 个 codegen mutation (改 emit instruction mnemonic / 改 operand encoding / 改 calling convention emit order)
     - 10 个 parser mutation (改 token table entry / 改 precedence / 改 AST node type)
     - 5 个 type checker mutation (改 type inference rule / 改 generic instantiation)
   - 跑 verification harness (per-test `.s` diff + regress 119/139) 期望 catch ≥ 24/30 (80%)
   - Failure: catch rate < 80% → harness 有 blind spot, 标 ⚠️ 写 workarounds.md

   - `compiler/tests/bootstrap/fixed_point_linux.sh` 跑 jhyy → jhyy_v1 → jhyy_v2 → jhyy_v3 在 docker `gcc:12` Linux 链
   - 期望 3 代 .il byte-equal + 5/5 main tests PASS

## Risk + rollback

**Risk 1**: N=10 跑 11 次 jhyy 编 main.jhyy 太慢 (单次 ~5-10 min, 11 次 ~1-2 hour)
- **Mitigation**: per `feedback_mcp_regress_timeout` (regress 600s timeout),N=10 走原始 Bash `run_in_background: true`, not MCP
- **Rollback**: revert Commit 1, 回到 v2.9.0 N≥3

**Risk 2**: Mutation catch rate < 80% (harness 有 blind spot, 6/30 没 catch)
- **Mitigation**: V.2 提前暴露; catch < 80% → 写 workarounds.md "mutation blind spot" 节 + v2.14.1 补 harness
- **Rollback**: mutation_test.py 仍是 ship artifact (即使 catch < 80%); 不 revert,但标 ⚠️

**Risk 3**: Linux 跨平台 parity 失败 (Linux 编 jhyy → jhyy 编 .jhyy 跑 fail)
- **Mitigation**: V.3 fail-fast 暴露;如 Linux parity 有 gap → 标 ⚠️ + write up cross-platform gap analysis (推 v2.14.1 或 v3.x)
- **Rollback**: fixed_point_linux.sh 是 ship artifact 但不挡 Win N=10; revert Commit 3 if Linux 全 fail

**Risk 4**: D43 closure long-term (N=10) 跟 v2.11.23 baseline `e6b6f1fa...` 不一致 (某一代 .il sha 偏差)
- **Mitigation**: V.4 fail-fast; 偏差代 → RCA (codegen 不稳定) → 修 codegen 不动 QBE IL emit path (per `feedback_codegen_amd64_multifn`)
- **Rollback**: N=10 closure 偏差 → re-baseline D43 (per `feedback_rca_first_root_cause`)
