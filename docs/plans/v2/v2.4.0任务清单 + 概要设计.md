## Stage 2: byte-equal 三件套脚本

### 2.1 范围

#### 2.1.1 byte_equal.sh 新建
- `compiler/tests/bootstrap/byte_equal.sh`（新）：
  - 三个 byte-equal 检查：
    - `.il byte-equal`: jhyy_v1 编 hello.jhyy 产 .il vs jhyy_v2 编同源产 .il byte-equal
    - `.s byte-equal`: 同上 .s
    - `.exe byte-equal`: 兜底 `gcc -g0 + strip + SOURCE_DATE_EPOCH + --build-id=none`
  - 验证 5/5 PASS on target test（per `feedback_fix_evaluation_rule`）

```bash
#!/usr/bin/env bash
set -euo pipefail

# byte_equal.sh - 验证 .il + .s + .exe 三层 byte-equal
# 用法: byte_equal.sh <input.jhyy> <jhyy_v1> <jhyy_v2>

INPUT="${1:?usage: byte_equal.sh <input.jhyy> <jhyy_v1> <jhyy_v2>}"
JHYY_V1="${2:?usage: byte_equal.sh <input.jhyy> <jhyy_v1> <jhyy_v2>}"
JHYY_V2="${3:?usage: byte_equal.sh <input.jhyy> <jhyy_v1> <jhyy_v2>}"
INPUT_BASE="${INPUT%.jhyy}"

PASS=0
FAIL=0

echo "=== byte-equal 验证: $INPUT ==="
echo

# === .il byte-equal ===
echo "[1/3] .il byte-equal:"
$JHYY_V1 --target=amd64_win "$INPUT" > "${INPUT_BASE}_v1.il"
$JHYY_V2 --target=amd64_win "$INPUT" > "${INPUT_BASE}_v2.il"
if diff -q "${INPUT_BASE}_v1.il" "${INPUT_BASE}_v2.il" > /dev/null; then
    echo "  ✅ PASS (.il byte-equal)"
    PASS=$((PASS + 1))
else
    echo "  ❌ FAIL (.il byte-equal)"
    FAIL=$((FAIL + 1))
fi

# === .s byte-equal ===
echo "[2/3] .s byte-equal:"
$JHYY_V1 --target=amd64_win "$INPUT" > "${INPUT_BASE}_v1.s"
$JHYY_V2 --target=amd64_win "$INPUT" > "${INPUT_BASE}_v2.s"
if diff -q "${INPUT_BASE}_v1.s" "${INPUT_BASE}_v2.s" > /dev/null; then
    echo "  ✅ PASS (.s byte-equal)"
    PASS=$((PASS + 1))
else
    echo "  ❌ FAIL (.s byte-equal)"
    FAIL=$((FAIL + 1))
fi

# === .exe byte-equal (兜底 gcc -g0 + strip + SOURCE_DATE_EPOCH + --build-id=none) ===
echo "[3/3] .exe byte-equal (兜底):"
export SOURCE_DATE_EPOCH=1234567890  # 固定时间戳
$JHYY_V1 --target=amd64_win "$INPUT" > "${INPUT_BASE}_v1.s"
$JHYY_V2 --target=amd64_win "$INPUT" > "${INPUT_BASE}_v2.s"
gcc -g0 -Wl,--build-id=none -o "${INPUT_BASE}_v1.exe" "${INPUT_BASE}_v1.s"
gcc -g0 -Wl,--build-id=none -o "${INPUT_BASE}_v2.exe" "${INPUT_BASE}_v2.s"
strip "${INPUT_BASE}_v1.exe" "${INPUT_BASE}_v2.exe"
if diff -q "${INPUT_BASE}_v1.exe" "${INPUT_BASE}_v2.exe" > /dev/null; then
    echo "  ✅ PASS (.exe byte-equal, 兜底生效)"
    PASS=$((PASS + 1))
else
    echo "  ❌ FAIL (.exe byte-equal)"
    FAIL=$((FAIL + 1))
fi

echo
echo "=== 结果: $PASS PASS / $FAIL FAIL ==="
[[ $FAIL -eq 0 ]] && exit 0 || exit 1
```

#### 3.1.1 regress.py 集成 byte-equal 检查
- `compiler/build/bin/regress.py`（改）：
  - 加 `test_byte_equal()` 函数：跑 byte_equal.sh 在 5 个 target test 上
  - 集成进 regress 流程（默认跑 byte-equal）
  - 5/5 PASS 必须（per `feedback_fix_evaluation_rule`）

```python
# regress.py 新增 byte-equal 检查步骤
def test_byte_equal():
    """byte-equal 三件套验证 (per D26 + feedback_fix_evaluation_rule)"""
    tests = ["hello.jhyy", "fib.jhyy", "ackermann.jhyy", "nqueens.jhyy", "struct_pass.jhyy"]
    jhyy_v1 = os.environ.get("JHYY_V1", "jhyy_v1.exe.exe")
    jhyy_v2 = os.environ.get("JHYY_V2", "jhyy.exe")

    passed = 0
    failed = 0
    for t in tests:
        result = subprocess.run(
            ["bash", "byte_equal.sh", t, jhyy_v1, jhyy_v2],
            cwd=compiler_tests_dir,
            capture_output=True,
        )
        if result.returncode == 0:
            passed += 1
        else:
            failed += 1
            print(f"FAIL: {t}")
            print(result.stdout.decode())
            print(result.stderr.decode())

    # per feedback_fix_evaluation_rule: 5/5 PASS on target test
    assert passed == 5 and failed == 0, f"byte-equal 5/5 PASS required, got {passed}/5"
    print(f"byte-equal: 5/5 PASS")
```
