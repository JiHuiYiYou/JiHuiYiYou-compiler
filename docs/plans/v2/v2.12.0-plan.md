**Audit 每个 test 流程**:
1. 编 self-backend `.exe` + QBE fallback `.exe`
2. diff `.s` codegen path 合理性 (per `feedback_codegen_amd64_multifn` silent-fail pattern)
3. 跑 fixture 自带 input,verify EXIT
4. **额外** multi-input EXIT boundary:
   - 空数组 / 零值输入
   - 边界值 (max i32 / min i32 / INT_MAX-1)
   - 负数 / 负 boundary
   - Loop iter count max (e.g. for i in 0..N 用 N=1, N=100, N=10000 三组)
   - 多 case branch dispatch (match 全分支 / 缺分支)
5. 验证 module-level 副作用 (per `feedback_codegen_amd64_run_zerobyte` — exit code 正确但副作用缺失)
6. 标 ✅ PASS / ⚠️ 疑 (further RCA) / ❌ FAIL (出 fix patch)
