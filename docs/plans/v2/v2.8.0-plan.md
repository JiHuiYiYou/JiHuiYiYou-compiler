## Phase 1: codegen_amd64 SysV emit 实现 (Commit 1)

### 1a. `codegen_amd64_emit_mem.jhyy` target_tag dispatch

**当前**: emit_mem 函数没 target_tag 参数,直接 emit Win ABI 汇编(e.g. `subq $32, %rsp` shadow space alloc)。

**新**: 每个 emit 函数加 `target_tag: i32` 参数;`target_is_win(target_tag)` 走 Win path(原逻辑 byte-equal hold),else SysV path。

```jhyy
fn emit_alloc(state: *u8, tok: *IlTok, target_tag: i32) -> i32 {
    if target_is_win(target_tag) == (1 as i32) {
        // Win ABI: shadow space + Win calling convention
        return emit_alloc_win(state, tok);
    }
    // SysV ABI: no shadow space, native 16B stack align
    return emit_alloc_sysv(state, tok);
}
```

**关键 invariant**: Win path 函数体 **逐字节不变**(byte-equal hold);SysV path 新增,mirror Win 路径但简化 SysV ABI 差异:
- 无 shadow space
- 无 `subq $32, %rsp` (Win ABI 在 call 前 reserve)
- 无 `addq $32, %rsp` (call 后 free)
- 16B 栈对齐在函数 entry (crt0 已做)
- SysV `emit_alloc` 用 `subq $N, %rsp` (无 shadow)

### 1b. `codegen_amd64_emit_ctrl.jhyy` target_tag dispatch

```jhyy
fn emit_func_header(state: *u8, tok: *IlTok, target_tag: i32) -> i32 {
    if target_is_win(target_tag) == (1 as i32) {
        // Win ABI: .globl main_jhyy + Win prologue + shadow reserve
        return emit_func_header_win(state, tok);
    }
    // SysV ABI: .globl main_jhyy + SysV prologue (no shadow, 16B align already in crt0)
    return emit_func_header_sysv(state, tok);
}
```

### 1c. `codegen_amd64_peephole.jhyy` target_tag

peephole 是 local folding on emitted .s,跨 target 同逻辑(只 fold redundant `mov %rax, %rax` 之类)。加 target_tag 仅 pass-through,内部不变。

### 1d. `main.jhyy` `run_backend` + `codegen_amd64_run` 传 target_tag

```jhyy

// codegen_amd64.jhyy:

    // ...

    // parse_and_emit loop 用 cg.target_tag
}
```

## Risk + rollback

**Risk 1** (Phase 1): codegen_amd64 emit_* 加 target_tag dispatch 漂移 Win ABI byte-equal。
- **Mitigation**: Phase 1 ship gate 要求 byte_equal_amd64.sh `--baseline` 20 PASS (旧 baseline hold — 任何 Win path 漂移立即 catch)。
- **Rollback**: revert Commit 1。Phase 1 不影响 SysV test (run_backend SysV path 之前 QBE 兜底,revert 后行为不变)。

**Risk 2** (Phase 1): codegen_amd64_run 接新参数破坏 Win emit。
- **Mitigation**: 默认 `target_tag = 0` (Win) 在所有 callers,Win emit 行为完全不变。
- **Rollback**: revert Commit 1。

**Risk 3** (Phase 2): 移除 vsock 调用影响 Windows host + WSL integration。
- **Mitigation**: `#ifdef _WIN32` guard — Windows host 仍走 WSL vsock;non-Windows 走 stub (callers 走 fallback)。
- **Rollback**: revert Commit 2 (B 部分)。

**Risk 4** (Phase 2): 5 sysv tests 真跑后才发现某个 emit (e.g. syscall / vararg) 没真实现。
- **Mitigation**: 5 sysv fixtures 覆盖 5 类 ABI 测试 — 任何 1 个 fail 立即 catch missing emit。
- **Rollback**: revert Commit 2 (B 部分 SysV emit),fix specific emit,re-merge。

**Risk 5** (Phase 3): D43 re-baseline 让旧 `cc894329...` 失效 → 后续 audit 找不到。
- **Mitigation**: per `feedback_changelog_umbrella` + `feedback_audit_single_commit_diff`,新 baseline ship 时强制写 `docs/logs/v2/d43-baseline-archive.md` 存档旧 baseline + commit message 引用。
- **Rollback**: revert Commit 3;但旧 baseline 已 archive 进 docs (即使 code revert,history 仍可查)。
