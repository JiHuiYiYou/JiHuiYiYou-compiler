## Context

**当前状态:借用检查停在「最小版」(W-105,词法作用域)。**

W-105 在 v4.0.18 已真修:
- (a)「`&mut` 真的能用」(v4.0.15)
- (b) **最小独占检查**(同作用域内双 `&mut` 互斥,新测试 `borrow_mut_conflict.jhyy` EXPECT-ERROR ✓)

⚠️ **但它是词法作用域** ⇒ **borrow 提前结束会误报**。
⇒ 完整版 = **NLL / Polonius** + 生命周期标注 `'a` + reborrow + 跨函数借用。

**lang-spec 附录 B 当前明列**:
> 完整 NLL / Polonius 借用检查、生命周期标注 `'a`、reborrow、跨函数借用

**这一版在 OS 线上的意义**:
内核的 `ptr<phys>` 派生、mapping cap、RCU 读侧**全都依赖借用语义** ——
`frame_phys(&cap, range)` 返回的 `ptr<phys>` 的 lifetime 必须绑定在 cap 的借用上
⇒ **借用检查不完整 ⇒ `ptr<phys>` 的生命周期保证就是空的**
⇒ 这直接削弱 v4.14(OS-14)的核心卖点。

---

## Goal

1. **生命周期标注 `'a` 可用**,并参与检查
2. **NLL / Polonius 借用检查** —— borrow 提前结束**不再误报**
3. **reborrow** 可表达
4. **跨函数借用**可检查
5. **v3.1.0 的 stub 借用检查用例全部仍过**(不许回退)

---

## Scope

### 任务 1 —— 生命周期标注

```jhyy
fn frame_phys<'f, R>(cap: &'f Cap<Frame, R>, range: Range<usize>)
    -> Result<ptr<'f, phys, R>, PhysError>
```
⚠️ lang-spec § 11.3 当前明列「生命周期泛型 `<'a, T>`」为**不支持** ⇒ 本版要把它从附录 B 移出去。

### 任务 2 —— NLL / Polonius

⚠️ **这是本版最难的一块** —— Polonius 是 NLL 的修正,涉及
「借用是否在最后一次使用后结束」的**数据流**判定,不是词法作用域能覆盖的。

⚠️ **风险提示**:Polonius 在 Rust 上是多年演进的结果。
⇒ **建议启动时先评估**:是否接受一个**子集**(如「借用结束点由显式 drop / scope 提示」),
还是完整实现。**宁可承认是子集,不要给一个半成品却宣称 Polonius。**

### 任务 3 —— reborrow

`&mut T` 从 `&mut T` 再借一层,且生命周期更短。

### 任务 4 —— 跨函数借用检查

把借用信息跨函数传递 ⇒ 需要**函数签名上可表达借用关系**
⇒ 这与 v4.10(OS-6)的 `fn(...)` 类型位置**强相关**。
