## 关键决策

- **M0 简化:不做循环优化 / LICM / GVN / instruction scheduling**(留 v4.x 末)— 仅基本局部优化
- **M0 优化级别仅 1 级**(`-O1`)— 不做 `-O2` / `-O3` 分级
- **M0 简化:优化 pass 仅 IR 层**(不做 .s 层 instruction scheduling)— 跟 v2.x 自写后端配套,V2-A 起 codegen_amd64 已有 peephole
- **不开新 worktree**

## 验收 / 5/5 ship gate

- 3+ 优化测试 5/5 PASS(opt_const_fold / opt_algebra / opt_dead_code)— `-O1` 跑通
- D43 re-baseline → **N23**(优化 pass 改 .il)
- `regress.py --all` → 2/2 gated PASS
- `jhyy_selfhost_check` byte-equal hold(`-O1` 跑 .il 应跟 `-O0` 等价语义)
- 优化后 codegen 产出 .il 不退步(全 104 + 新 test PASS)
- 优化后 codegen .s 长度 ≤ 不优化 +5%(性能不退步)

| 风险 | 影响 | 修复 |
