## 关键决策

- **M0 简化:async runtime 单线程 + 可选 worker pool**(per 2026-09-01 OS 决策 — 不做完整 tokio 风格)
- **M0 简化:不做 async closure**(留 v4.x 中)
- **M0 简化:不做 async trait**(留 v4.x 中)
- **state machine 编码**(per Rust async 路径):async fn 编译为 enum state machine,无 stackless coroutine 复杂性
- **不开新 worktree**

## 验收 / ship gate

- 3+ async 测试 5/5 PASS(async_basic / async_spawn / async_join)
- D43 re-baseline → **N17**
- `regress.py --all` → 2/2 gated PASS
- `jhyy_selfhost_check` byte-equal hold
- async executor 跑通 1000 个并发 task 不死锁

## 风险 + 缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| state machine codegen 复杂度高 | ship 推迟 | 复用 sema 已有的 enum codegen 路径;state machine 是 enum 的特化 |
| async runtime leak / deadlock | 跑测试 fail | leak detector + 1000 task 并发测试 |
| async + lifetime 交互(self-referential future)| codegen 复杂度 | M0 不做 self-referential(Pin 强制);留 v4.x 中 |
