## 关键决策

- **M0 简化:memory model 6 个 order 全支持**(Acquire / Release / AcqRel / SeqCst / Relaxed / Consume)
- **M0 简化:thread 仅 OS thread,不做 green thread / coroutine**(async 留 `v4.2.0-plan.md`)
- **M0 简化:多架构 Cap<T> ABI 仅基本 INTEGER + 寄存器对齐**(完整 8-class 分类器留 v4.x 末)
- **不开新 worktree**

## 验收 / 5/5 ship gate

- 4+ atomic / thread / cap 测试 5/5 PASS
- D43 re-baseline → **N26**
- `regress.py --all` → 2/2 gated PASS
- `jhyy_selfhost_check` byte-equal hold
- 多线程 producer/consumer 同步测试 1000 次不 fail
- aarch64 / riscv64 跨架构 ABI 通过 cross-compile test(WSL / docker)

## 风险 + 缓解

| 风险 | 影响 | 修复 |
|------|------|------|
| Memory model 跟 codegen 主路径交互 | regress 退步 | atomic 走独立 codegen 路径 |
| 多架构 ABI 实现复杂度 | ship 推迟 | aarch64 / riscv64 复用 v2.x 自写后端 codegen_amd64 模式;按架构 1 个 1 个做 |
| 多线程 cap race condition | OS 端 fail | OS 联调测试;失败时回退到 3g + 3c + 3f stub |

- Distributed cap / capability delegation 跨机器(留 v4.x 末)
