### Step 2 — 1-iter RCA: 综合 fix direction

**Expected 综合 fix (1 commit, ~150-300 LOC):**

1. **Alloc pool disjoint 真修** (`codegen_amd64_state.jhyy:857-870`):
   - `cg_alloc_slot` 第一次调用: init_off 改用 `-(32 + (local_max+1)*8 + 64)`
   - local_max = per_fn_max[fi] - per_fn_max[fi-1] (or per_fn_max[0] for fi=0)
   - fi = cur_fn_idx - 1 (post-bump, body path)

2. **frame_size 公式更新** (`emit_ctrl.jhyy:546-573`):
   - alloc_pool_size = `(32 + (local_max+1)*8 + 64) + per_fn_alloc[cur_fn_idx]`
   - frame_size = max(formula_pool_size, alloc_pool_size)
   - 16-align per SysV/Win

3. **Cur_fn_idx 索引语义统一注释** (`emit_ctrl.jhyy:519, 537` + `state.jhyy:769, 1605`):
   - 加 explicit `let fi: i64 = (*s).cur_fn_idx - 1;` 局部 alias (per `feedback_jhyy_no_forward_ref` 防 cascading)
   - 注释 clear "cur_fn_idx in body = function_index + 1; per_fn_max[fi] = per_fn_max[cur_fn_idx - 1]"

4. **Hoist audit 全 cover** (`emit_ctrl.jhyy:519, 529, 551` + `state.jhyy:1601-1607` + 25 sites 跨 10 src0/ 文件):
   - grep `* (8 as i64)` ptr_add_u8 patterns → 全部 hoist to `(idx - 1)` 局部
   - 自动 script 辅助 (per W-097 audit expansion)

5. **Sub-bug 真修** (per W-074.6 sub-bug #3 已 ship, sub-bug #1+#2 已 ship; 无残留)
