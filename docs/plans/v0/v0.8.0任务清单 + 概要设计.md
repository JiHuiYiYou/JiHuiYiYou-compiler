# v0.8.0 任务清单 + 概要设计

## Context

v0.7.0（7A enum first-class + 7B const struct array）已通过。v1.0.0 v1.x 自举 sprint 4（ir + codegen 翻译）收尾后发现 **9 个自举过程暴露的 codegen workaround 体系**（W-001 ~ W-009），详情见 [`architecture-refactor.md` § 1.1.2](../roadmap/architecture-refactor.md) + [`workarounds.md`](../../internal/workarounds.md)。

v0.8.0 定位：**Stage 0 closure 解锁** = jhyy_v1 编 src0/arena.jhyy 通过 QBE typecheck 入口。v0.8 末真实状态 = jhyy_v1 编 jhyy_v1 跑 regress **12 OK / 47 总**（剩余 35 = 8 CERR + 8 AV + 25 STK，详见 [§ 当前状态](#当前状态)）。

按 v1.0.0 L1 计划：v0.x patch 只修 bug，**不引入新特性**。v0.8.0 同样不引入新语法。

让 `jhyy_0 (C 编译) 编 main.jhyy → jhyy_1` 跑通，且 `jhyy_0` 和 `jhyy_1` 对相同 .jhyy 测试集产出 **byte-equal .il**。
