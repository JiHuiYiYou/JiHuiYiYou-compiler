## Sprint 3a: 内联汇编（OS P0-1）

### 改动范围

- lexer: 新增 `asm` 关键字 + 大括号字面量识别
- parser: `asm { "..." : outputs : inputs : clobbers }` 五段式（初期可简化只 outputs/inputs/clobbers）
- AST: 新增 `NODE_ASM` 节点（保存汇编字符串 + 输入输出表达式列表 + clobber 列表）
- codegen: IR 层记录 asm 块 → 最终 `.s` 输出文件中插入对应汇编
- spec 增补：lang-spec § 14 asm 块语法

### 用法示例

```rust
fn outb(port: u16, value: u8) {
    asm {
        "out %al, %dx"
        : /* 无输出 */
        : "d"(port), "a"(value)
    };
}
```

QBE 不原生支持内联汇编。方案：IR 层记录 asm 块 → 最终 `.s` 文件中插入对应汇编。

> **跟 v2.x 顺序敏感**：v2.x 自写 QBE 后端若已完成，asm 走自写后端"escape hatch"路径；若 v2.x 未完成，仍走 C 版 QBE 工具链的 .s 输出路径。具体顺序由 user 后续决定。

### 验收标准

- [ ] asm 块语法解析正确
- [ ] 汇编代码嵌入最终 `.s` 输出
- [ ] 测试：I/O 端口读写（`outb` / `inb`）
- [ ] **跟 v2.x 自写后端顺序不阻塞**(per `v2.0.0-os-prep.md` § 3 决策 8 / coordination.md D42):v2.x 自写后端未完成时,asm 走 QBE 工具链 .s 输出路径(直接插入汇编);v2.x 完成后,asm 走自写后端 "escape hatch" 路径。**3a 启动不依赖 v2.x 完成**

## Sprint 3b: naked fn（OS P0-2）

### 改动范围

- 新增 `#[naked]` 函数属性
- codegen: 对 `#[naked]` 函数不自动 emit prologue/epilogue（不 push rbp，不 mov rsp, rbp；不 epilogue ret）
- 用途：异常/中断 entry（自己控制寄存器/栈帧）、`_start`、boot 段代码
- spec 增补：lang-spec § 14.2（`#[naked]` attr）

### 用法示例

```rust
#[naked]
fn interrupt_entry() {
    // 编译器不插入任何 prologue/epilogue
    // 用户自己控制 push / mov / iret 等
}
```

### 验收标准

- [ ] `#[naked]` 函数的 emit 不含自动 prologue/epilogue
- [ ] 测试：手写一段 naked 中断 handler，能正确保存现场 + iret

## Sprint 3c: volatile load/store（OS P0-3）

### 改动范围

- 新增 `volatile *T` 语法（volatile 指针）或 `volatile_load<T>(p) / volatile_store(p, val)` intrinsic
- codegen: volatile 访问 emit `volatile` 前缀或用 `mutex` 之类的内存屏障 hint；防止 QBE/编译器重排 + 强制走 MMIO 内存语义
- 用途：MMIO 设备寄存器读写
- spec 增补：lang-spec § 14.3（`volatile *T`）

### 用法示例

```rust

let v: *volatile u32 = 0xFEE00000 as *volatile u32;  // APIC 寄存器
let current = *v;             // volatile load
*v = current | 0x100;          // volatile store
```

- [ ] volatile load/store 编译期不被优化器消除/重排
- [ ] 测试：连续 100 次 volatile store 到同一地址，runtime 行为正确（不被合并）

## Sprint 3d: no_std（OS P0-4）

### 改动范围

- 新增 `#[no_std]` crate 属性 + 配套 `core` 库（无 libc 依赖的最小库）
- 标准库分层：`core`（无 libc，所有 jhyy 程序都可用）+ `std`（`core` + libc 包装，仅 hosted 程序可用）
- sprint 1 util.jhyy / arena.jhyy 移植到 `core`；运行时 + FFI 桥放 `std`
- spec 增补：lang-spec § 15（`#[no_std]` crate attr + `core` 库清单）

### 用法示例

```rust
// kernel.jhyy — 不依赖 libc
#[no_std]
fn kernel_entry() {
    let console = Console::new(0x3F8);  // UART 串口
    console.write("Hello from kernel\n");
}
```

### 验收标准

- [ ] `#[no_std]` 程序不 link libc
- [ ] `core` 库包含最小工具（memcpy / memset / slice 操作 / fmt）
- [ ] 测试：`#[no_std]` 程序在 freestanding 环境下能跑（编 bootable 二进制）

## Sprint 3g: &mut + lifetime（OS P1-7,**M4 启动硬前置 P0**）

> **拆分**(per coordination.md § 3 D27):**3g 主体 → 3g.5 → 3g.7 三段独立 sprint,顺序强制不可调换**。
> **OS 对接**(per D18):M4 起 OS 代码用 `Cap<T>`;**sprint 3g 优先级 = P0(M4 启动硬前置,不推迟)**。
> **M1-M3 OS 代码**:`*mut T` raw pointer + 手动 discipline(per D11);M4 起改 `&mut T` + lifetime。

### 3g 主体:&mut + lifetime + Cap<T> 8 条编译期规则 + 相关 attribute

#### 设计

```rust
fn push_back(v: *mut Vec, val: i32) {
    let mut vec: &mut Vec = &mut *v;   // 独占借用
    vec.push(val);
}

let mut v = Vec::new();
push_back(&mut v, 42);     // OK
// 期间 v 不能被其他地方借用
```

借用检查规则(同 Rust subset):
- 同一作用域内,一个值要么有多个 `&T`(共享借用),要么有一个 `&mut T`(独占借用)
- 借用期跨越 borrow expression 的使用范围(**非词法作用域**,简化版 lifetime)

#### 改动范围

- **lexer**: 新增 `mut` keyword 在 `&mut` 位置
- **AST**: 新增 `NODE_BORROW_MUT` 节点类型
- **sema**: lifetime tracking(每个借用一个 generation 编号,活跃期跟踪,conflict 报错)
- **codegen**: 区分 `&T` vs `&mut T` 的 QBE emit
- **Cap<T> 8 条编译期规则**(per coordination.md § 3 D12 锁):
  1. `#[cap_constructor]` 白名单 + 普通函数体禁止 `Cap { ... }` 字面量 — AST + sema
  2. `Cap<T1> ≠ Cap<T2>` — sema type compare
  3. `Cap<T>` mark move-only(隐式 copy 报错)— sema hardcoded
  4. `Cap<T> as *u8` 报错;`into_raw` 必须 `unsafe` block + warning — sema
  5. revocation = lazy invalidation — codegen emit `is_valid()` trait 调用
  6. `is_valid()` 标准库 trait — sprint 3l 阶段(sprint 3g 留接口)
  7. 函数参数 `Cap<T>` = move 语义 — sema
  8. `&mut Cap<T>` 借用 = `&mut` 规则 — 共享借用检查
- **`#[ipc_handler(msg: M, env: *E)]` attribute**(per coordination.md § 3 D13/D20 锁):
  - sprint 3g 内 compiler 实现:sema 检查 + codegen dispatch table 生成
  - **不进 lang-spec**(per 原则 5 + 1)
- **`unsafe cap { ... }` block 语法**(per coordination.md § 3 D15/D19 锁):
  - 复用 `unsafe` 块语义,加 `cap` 关键字
  - 进 lang-spec § 19(待增)— 不放 OS std lib
  - sprint 3g 实现(不需要 `#![feature(unsafe_cap)]` gate)
- **`Cap::provenance() -> DebugInfo` 接口**(per coordination.md § 3 D14/D21 锁):
  - 进 lang-spec § 21(待增)— OS 独有 debug, **不进 std lib**
  - sprint 3g 留接口;OS 端 codegen 实现 debug build 携带 provenance side table
  - **wire format / Confidence 三级标记 / DAG 增强** → [`../../../jhyy_OS/docs/v0.0.4-debug-abi.md`](../../../jhyy_OS/docs/v0.0.4-debug-abi.md) § 4 + § 7(**🔒 2026-08-12 锁**,Q-Compiler-007 已闭环 / D41)
- **`DebugEventKind` enum / `Confidence` 三级标记**(per coordination.md § 2.2 Q-Compiler-007 ✅ 闭环):
  - 进 lang-spec § 22(待增)— 跟 § 21 同属 debug infra,跟 ProvenanceInfo 一起定
  - wire format(c-typedef + nested payload 约定)→ [`../../../jhyy_OS/docs/v0.0.4-debug-abi.md`](../../../jhyy_OS/docs/v0.0.4-debug-abi.md) § 2 + § 3(**🔒 已锁**)
  - ✅ **前置已解除**(Q-Compiler-007 2026-08-12 闭环 / D41)。实施时按 review 结论落三条语法约束:
    - jhyy-side 类型名为 **`ErrChain`(无泛型参数)** —— 泛型是 sprint 3i(v3.2+),晚于 3g;注意 `Cap<T>` 是 phantom-type 特例(sema hardcoded),不代表 3g 有泛型
    - 变长字段按 **D40 规则**取类型:wire-format 有 `*_len` → `[*]T` 切片;NULL 结尾链 → `*T` 裸指针(无 `[T]` 无尺寸数组类型)

- **cap-offset 表 = 双路径 emit**(per coordination.md § 3 D16 锁):
  - 主路径:codegen 时**内联到 syscall wrapper**(快路径)

## Sprint 3i: 泛型（单态化）

### 设计

```rust
fn max<T>(a: T, b: T) -> T {
    if a > b { a } else { b }
}

let x = max::<i32>(3, 5);    // 生成 max_i32
let y = max::<i64>(100, 200); // 生成 max_i64

type Vec<T> = struct { data: *T, len: i32, cap: i32 };
type Option<T> = enum { Some(T), None };
```

单态化在 sema 之后、codegen 之前执行：收集所有泛型调用 → 为每种具体类型参数组合生成专用 AST → 替换原调用。

### 实现步骤

1. **语法**：`fn name<T, U>(...)` 和 `name::<T>(args)`
2. **泛型参数存储在 AST**：类型参数列表挂在函数声明节点上
3. **调用处收集具体类型**：AST 遍历，找到泛型函数调用
4. **单态化**：为每种 `(函数, 类型参数组合)` 生成副本
5. **类型检查**：在单态化后的 AST 上执行（而非泛型 AST）

### 验收标准

- [ ] 泛型函数定义和调用
- [ ] 泛型 struct 和 enum
- [ ] 多个类型参数 `fn foo<A, B>()`
- [ ] 泛型参数推断（可从实参推断时省略 `::<T>`）
- [ ] 单态化后 IR 正确

## Sprint 3m: 基本优化

在 AST → IR 之间加入优化 pass：

| Pass | 内容 | 复杂度 |
|------|------|--------|

| 死代码消除 | `if false { X } else { Y }` → `Y` | 低 |
