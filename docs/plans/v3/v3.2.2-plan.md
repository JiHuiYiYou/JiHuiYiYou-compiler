## Scope

### 新建 std lib 模块(纯 jhyy,无泛型 / 无借用)
| 模块 | 功能 | 备注 |
|------|------|------|
| `std/mem.jhyy` | memcpy / memcmp / memset | 纯 jhyy byte 循环;替代 v1.0.0 编译器 `memcpy` C 调用 |
| `std/fmt.jhyy` | 格式化字符串(自实现)| 替代 v1.0.0 编译器的 C 运行时 printf |
| `std/string.jhyy` | 字符串操作(拼接 / 查找 / 比较 / 切片)| 替代 v1.0.0 编译器的 C 运行时 string |
| `std/arena.jhyy` | Arena allocator(从 v0.x C 移植到纯 jhyy)| 编译器自身用 |

### 改动
| 改动 | 文件 | 估算 |
|------|------|------|
| 编译器 codegen 集成 std lib 模块 | `compiler/src0/main.jhyy` + `codegen.jhyy` | ~150 行 |
| arena API 兼容 v0.x C 版接口(per D22) | `std/arena.jhyy` | ~50 行(对齐 API 签名)|

### 测试 + 文档
- `tests/std_mem_basic.jhyy` + `tests/std_fmt_basic.jhyy` + `tests/std_string_basic.jhyy` + `tests/std_arena_basic.jhyy`(~200 行 + SKIP)

## 风险 + 缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| std lib codegen 集成 codegen 主路径漂移 | regress 退步 | std lib 走独立 codegen 路径,失败时 fallback;测试覆盖 |
| `string.jhyy` 不借用 → API 难用 | UX | 后续 sprint(v3.x 中)加借用 string view |
| jhyy 编译器自身迁移 string.jhyy 触发大量改动 | ship 时间线 | 集成测试在 ship gate 跑;如失败 hotfix 进 v3.x patch |
