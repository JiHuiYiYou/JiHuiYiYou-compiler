## 风险 + 缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| f32/f64 SysV ABI 走 SSE regs 跟 INTEGER regs 冲突 | 跨 target 联调 fail | abi_amd64_sysv.jhyy 加 SSE class 跟 INTEGER 分规则;v2.7.0 ship 后填 |
| 浮点字面量精度漂移(lexer 误把整数当浮点)| test fail | lexer 显式区分 `.` 后有数字 vs 无 |
| codegen 浮点 emit 漂移 regress | regress 退步 | 浮点 emit 走独立 codegen 路径 + 测试覆盖;失败 fallback |
