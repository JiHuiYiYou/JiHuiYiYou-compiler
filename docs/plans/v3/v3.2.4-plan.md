## Scope

### 新建 std lib 模块(泛型)
| 模块 | 功能 | 备注 |
|------|------|------|
| `std/vec.jhyy` | 泛型动态数组 `Vec<T>` | 用 `mem.jhyy` memcpy / memcmp;push/pop/len/index |
| `std/map.jhyy` | 泛型哈希表 `Map<K, V>` | hash 函数用 `string.jhyy`(string hash)或 K 实现 `hash()` |

## 关键决策

- **M0 简化:`Vec<T>` 用 `[T]` slice + `arena.jhyy` allocator**(per 2026-09-01 拆分)— 不实现完整 drop semantics,leak-OK
- **M0 简化:`Map<K, V>` 用 open addressing + linear probing**(避免 B-tree 复杂度)
- **M0 简化:`Map` 不支持并发**(并发留 v3.x 中)
- **jhyy 自身迁移触发条件**:本 sub-sprint ship gate **不**要求 jhyy 自身迁移(refactor 范围大,留 v3.x 中 hotfix)— 但建议 ship 后立即做
- **不开新 worktree**(per 2026-09-06 user)

## 验收 / 5/5 ship gate

- `std/vec.jhyy` + `std/map.jhyy` 每个有源码 + 单元测试(5+ 测试 / 模块)
- 泛型 Vec<T> + Map<K, V> 集成测试 5/5 PASS
- D43 阶段性 self-equal hold
- `regress.py --all` → 2/2 gated PASS
- `jhyy_selfhost_check` → N13 → N14 byte-equal hold

## 风险 + 缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 泛型 std lib codegen 主路径漂移 | regress 退步 | std lib 走独立 codegen 路径;test 覆盖 |
| `Map<K, V>` hash 函数实现难(非 string key) | UX | M0 提供 `string.jhyy` hash 路径 + user 自实现 `hash()`(可选)|
| jhyy 自身迁移 `Vec<T>` refactor 触发大量 codegen 改动 | ship 时间线 | ship gate 不要求迁移;失败时 hotfix 进 v3.x patch |

## Out of scope

- 完整 drop semantics(留 v3.x 中)
- `Map<K, V>` B-tree / 红黑树版本(留 v3.x 中)
- 并发 `Map`(留 v3.x 中)
- `LinkedList<T>` / `HashSet<T>` / `BTreeMap<K, V>`(留 v3.x 末)
- 借用 `&Vec<T>` / `&Map<K, V>`(留 v3.x 中)
