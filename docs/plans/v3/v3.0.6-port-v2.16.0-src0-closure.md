- **RCA finding (2026-09-23, 2026-09-23 Ph.3 ship 后追加)**: V3 self-backend `codegen_amd64_run` 对 fmod 类测试 produce 0-byte .s。Root cause **多层**:
  - **Layer 1 (W-083, Ph.3 真修)**: lexer `'d'/'s'/'u'/'e'/'t'` prefix handler 不识别 conversion ops (dtosi/stosi/swtof/exts/extu/...) → lex_il 返 -1 → codegen_amd64_run 没 emit → 0-byte .s
  - **Layer 2 (W-086 NEW, Ph.3 ship 时记录, defer 真修)**: emit_copy / emit_binop / emit_conv 字段约定冲突

    - emit_binop (line 459-465) 读 int_val = dst_id (跟 emit_copy 冲突!)
    - emit_call (line 312) 读 int_val = ret temp id
    - '%' LHS handler (codegen_amd64_lexer.jhyy line 680) **不写** int_val/text_len, 留 0 从 lex_init_token
    - 结果: emit_copy 读 src_int = 0, src_text = NULL → 默认 IMM path → movq $0, dst → 所有 copy 写入 0
    - 结果: emit_binop 读 dst_id = 0 → dst_off = -32 永远 → 所有 binop 写 -32(%rbp) → 后续 read %t<N> 读到错 slot
