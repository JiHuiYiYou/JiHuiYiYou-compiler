## Scope

### 新建 std lib 模块
| 模块 | 功能 | 备注 |
|------|------|------|
| `std/io.jhyy` | 文件读写,stdin / stdout / stderr | 平台调用 Win32 / POSIX |
| `std/os.jhyy` | 系统调用包装(open / read / write / exit / getenv) | 平台调用 Win32 / POSIX |

### 改动
| 改动 | 文件 | 估算 |
|------|------|------|
| std lib 模块路径在 codegen 集成 | `compiler/src0/main.jhyy` | ~30 行 |
| 平台调用 dispatch(Win32 vs POSIX) | `std/io.jhyy` + `std/os.jhyy` | ~80 行 |

### 测试 + 文档
- `tests/std_io_basic.jhyy` + `tests/std_os_basic.jhyy`(~100 行 + SKIP)
- `docs/abis/jhyy-lang-spec-stdlib-io-supplement-v3.2.3.md`(~150 行)

## 关键决策

- **M0 简化:std lib IO 不依赖 async / thread**(per 2026-09-01 拆分)
- **M0 简化:std lib IO 用平台调用 Win32 / POSIX**,**不**依赖 libc(避免 runtime dep)
- **M0 简化:std/os 不暴露 cap / fd table**(M11 OS launch 后再做 v3.x 中)
- **不开新 worktree**(per 2026-09-06 user)

## 验收 / 5/5 ship gate

- `std/io.jhyy` + `std/os.jhyy` 每个有源码 + 单元测试(5+ 测试)
- 文件读写 / 系统调用集成测试 5/5 PASS
- D43 阶段性 self-equal hold
- `regress.py --all` → 2/2 gated PASS
- `jhyy_selfhost_check` → N12 → N13 byte-equal hold

## 风险 + 缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| std lib IO 平台调用 codegen 主路径漂移 | regress 退步 | std lib 走独立 codegen 路径;Win32 + POSIX 双实现测试覆盖 |
| std lib IO 不依赖 libc → jhyy_OS kernel 启动失败 | M11 阻塞 | 验证 OS launch 端到端;失败时 hotfix 进 v3.x patch |
