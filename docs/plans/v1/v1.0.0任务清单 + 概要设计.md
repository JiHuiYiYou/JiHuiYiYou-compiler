## Sprint 1: 基础设施 (arena + ffi + util + jhyy_helpers)

### 1.1 范围
- `compiler/src/arena.c` (bump allocator, 94 行) → `compiler/src0/arena.jhyy`（参照 `compiler/tests/examples/arena_test/arena.jhyy` 翻译稿复制修订，v0.6 验证过的不重翻译）
- `compiler/src0/ffi.jhyy`（**新文件**，对齐 v1.x L1 计划 Step 2.3）：列 libc 必需函数（malloc, free, memcpy, memset, sprintf 单 i32, fopen, fread, fwrite, fclose, strlen, strcmp, system, exit）+ jhyy_helpers externs（jh_fputs_stderr/stdout/fopen_wb 等）
- `compiler/src0/jhyy_helpers.c`（**新 C 文件**）：桥接 jhyy extern fn 拿不到的 libc 资源（FILE* 流 / fopen 二进制模式 / stderr 行号前缀等）。jhyy extern 调用，C linker 链接。**这是 C 端写的唯一跨 FFI 桥**，v1.0 全程存在。
- `compiler/src0/util.jhyy`（**新文件**）：
  - StringBuilder（sb_init/sb_append/sb_append_cstr/sb_appendf/sb_cstr/sb_reset/sb_free，sb_appendf 内部 sprintf 单 i32）
  - HashMap（FNV-1a + 开放寻址 + 线性探测）
  - Diagnostic（单字符串参数，变参由 StringBuilder 拼好）

### 1.2 依赖
- 无（基础层）

### 1.3 验收
1. **编译验证**: jhyy 编译器（C 版）编译 src0/{arena,ffi,util,helpers,driver}.jhyy + link jhyy_helpers.o
2. **行为验证**: arena 跑 v0.6 stage 0 6 项测试；util 测 StringBuilder append 1000 次 + HashMap put/get 1000 项 + Diagnostic 输出格式；helpers 测 jh_fputs_stderr 走 stderr 输出
3. **回归验证**: `regress.py` 全过（**M1 降级**：用 jhyy_1 跑回归推到 sprint 5）
4. **M1 里程碑（降级）**: src0/{arena,ffi,util,helpers} 在 jhyy 测试中跑通 + regress.py 持平（**不是全过**，见 § 完成定义）

### 1.4 风险
- **util.jhyy 是 jhyy 版编译器内部工具库**。C 端 codegen.c / symtab.c / sema.c **不重写、不删**（保留到 v2.0+），C 端代码跟 jhyy 版编译器**没有调用关系**。
- jhyy 字符串 / 哈希表实现：jhyy 无 stdlib 字符串函数，自实现（用 `[*]u8` slice）
- **stderr/stdout 流地址无解**：jhyy extern fn 不能拿 `FILE*` 地址（C 全局符号）。**sprint 1 加 C helper lib `compiler/src0/jhyy_helpers.c`** 桥接：提供 `jh_fputs_stderr(s)` / `jh_fputs_stdout(s)` / `jh_fopen_wb(path)` 等。
- **多 extern 同名链接冲突**：jhyy extern fn 没别名机制，多个 extern 映射到同一 C 符号 gcc 报重定义。**走单 i32 printf 风格**（v0.6 已验证：`extern fn printf(fmt: *u8, val: i32) -> i32;`），多段拼接由 StringBuilder.sb_appendf（内部 sprintf 单 i32）实现。
- 变参 FFI（fprintf `...`）实测 parser 不接受：lang-spec § 13.2 行 813-814 示例跟 parser 行为冲突，sprint 末提 spec patch 删示例。
