## Measurement floor

Every wall-clock number above includes the cost of getting the process started at all. That floor has **two** parts:

1. the harness's own process-creation cost (Python `subprocess` + Windows `CreateProcess` + C-runtime init) — roughly the same for both runtimes;

2. the program's own startup cost — **jhyy is ~6 ms more expensive than plain C** here, because the jhyy runtime shim (`compiler/runtime/runtime.c`: `GetCommandLineW` / `CommandLineToArgvW` / encoding conversion / `setvbuf(_IONBF)`) runs first.

The ratios above subtract this floor (per runtime) so they compare the programs' own work. The `floor share` column says how much of each task's runtime the floor accounts for; above 25% the ratio is not reported at all, because the floor's own measurement error would dominate it.

## Caveats

See `bench/METHODOLOGY.md` for the full list. The short version:

- jhyy has **no optimizer** — every jhyy number is `-O0`-quality codegen.
- gcc `-O0` is the codegen-quality floor; gcc `-O2` is a reference, **not** a bar.
- jhyy binaries link **ucrt64 libc** — tasks marked `libc != none` partly measure libc.
- **jhyy's stdout is unbuffered** (`setvbuf(_IONBF)`) — every task therefore prints one checksum, never bulk output.
- jhyy **cannot pass floats to C variadic functions** — float tasks are compared by IEEE-754 bit pattern, not decimal rendering.
- Float tasks are byte-compared against the **gcc `-O0`** build only; `-O2` may reassociate floating point.
- Tuning is asymmetric — the C twin is deliberately naive so both sides run the same algorithm.
- **jhyy programs start ~6 ms slower than plain C** (the C-runtime shim) — a fixed handicap that dominates short programs.
- Absolute numbers are **not comparable across machines** — only same-environment relative multiples are.
- **Wall-clock varies run to run** (up to ~25% between two runs on the same machine) — treat these as orders of magnitude, not precise values.
- Microbenchmarks are not real programs — the self-host compile time is the 'real program' data point.
- This suite measures **codegen quality**, not the standard library.
